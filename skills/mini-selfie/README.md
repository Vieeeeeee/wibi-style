# Wibi Style · 俯拍迷你自拍

适合五官清楚的单人自拍，保留神态与配饰，变成宽地面上的巨头迷你小人。

当前版本：`v1.0.0` · beta

适用清晰的成年单人自拍；目前未验证多人、动物或纯场景。自拍未拍到的下装、鞋子和地面会自然补全。宽地面v13已验证两例，展示中的其余四例沿用v9；暂未做v13三图重复验证。仅需上传自拍，无需风格参考图。

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/mini-selfie
```

安装器只下载这一款 Skill。装完不用做别的，第一次调用时它会自己打招呼并告诉你下一步。

本款运行需要的参考图：`0` 张。需要时已放在 Skill 自己的 `assets/references/` 中，会随本款一起安装；用户无需再次上传。
