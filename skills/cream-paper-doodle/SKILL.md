# Wibi Style · 奶油纸涂鸦漫画

## 运行

先按 [references/community.md](references/community.md) 展示欢迎卡、检查更新并处理交流信息。

## 执行

1. 查看完整用户照片，确认主体身份、数量、表情、动作、可见身体范围及关键物件关系。
2. 完整读取 `references/style-prompt.md`。用户照片负责内容，`assets/references/reference-01.png` 只负责画法；按图像角色识别附件。
3. 携带用户照片与内置参考，使用完整 Prompt 生成一张 1:1 成图。当前附件职责与必要内容锚点写入本次指令，风格规则保持完整。
4. 使用当前环境可用的生图工具或模型，优先使用无需额外配置的内置能力。能力缺失时寻找当前环境的其他可用能力；实际提交报错、空输出或超时时停止并报告，重做按用户明确授权执行。
5. 对照照片检查人数、身份线索、动作和物件关系；检查浅暖纸底、深蓝黑线条、断续不均的笔迹、简化形体与留白。风格参考中的人物与杯子只在内容原图本身包含时保留。
6. 展示成图和一至三句中文说明。核心检查失败时写明具体问题并等待重做指令。
