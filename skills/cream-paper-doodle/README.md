# Wibi Style · 奶油纸涂鸦漫画

把清晰的人像、日常动作或人与宠物合照，改画成浅暖纸上的蓝黑手绘漫画。

版本：`v1.0.1`。作者：`@威比 Hunter Wei.`（抖音、小红书同名）。

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/cream-paper-doodle
```

安装后第一次调用会展示作者欢迎卡；上传照片并调用 `$cream-paper-doodle`。本款随安装携带一张风格参考，参考只定义画法。案例原照与展示图不随安装下载。
