# 都市机械赛璐璐线上版 Prompt

把用户上传的真实人物照片彻底重画成 1:1 方形的 1980 年代日本都市科幻漫画草绘。用户照片决定人物身份、动作、服装款式与层次、配饰、手中物及接触关系；系统携带的风格参考只决定画法，不继承参考人物。只保留最有辨识度的脸、神态和一个主要动作或物件，不增加原图没有的内容。

人物身份只由头脸外轮廓、发型、年龄感、头部角度和原本眼神方向保持；五官按风格参考的少线条、偏轴、自然不对称结构重新设计。人物成年、干净、松弛、微微痞气；根据原照神态保留表情强度，不强行改成统一表情。用少量粗黑马克笔线概括脸、头发、手和衣服，线条松动、有粗细、断点、重描和试探痕迹。

脸部与颈部大面积保留纸白，用灰粉画 2–4 块明显的平涂硬边阴影：从眼窝、鼻侧、颊部、下颌和颈侧中按当前头部角度取舍。阴影合计占脸与颈面积约 18%–25%，边缘像手工涂出的不规则色块，内部色值均匀，不用柔光、渐变或写实体积。

画面只用纸白、朱红、近黑和少量灰粉。所有可见服装统一重构为朱红，保留原有领口、袖型、叠穿、褶皱和配饰关系；红色像没涂满的马克笔块，肩部和衣摆逐渐漏白、断线、收笔。原图中的主要物件保持可辨识，只有服装强制改红。

根据原片选择头肩、半身或动作特写，允许重新裁切和放大人物；完成动作所需的手、持有物与接触点必须保留。人物与主要物件聚成一个完整主体组，略微偏离中心，占画面约 55%–65%，不碰画面四边；在人物视线或动作朝向一侧保留连续纸白。

在连续纸白中最多放一条 2–5 个字符的竖排日文手写旁注，面积低于画面 4%，像随手写在原稿边缘。文字必须准确可读；无法准确生成时保持空白。

排除：换脸、照片描边、写实皮肤、精修五官、光滑数码线、柔和渐变阴影、摄影光影、复杂背景、密集排版、大标题、英文副标、Logo、日期、期号、边框、刻度、说明文字、品牌标志、水印、乱码。
