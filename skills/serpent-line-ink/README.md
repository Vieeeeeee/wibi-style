# Wibi Style · 蛇发游线墨绘

把用户上传的单人头肩、近景或半身照片转换成蛇发即兴钢笔墨绘肖像：暖象牙纸大片留白、粗细突变的自由长线、三至五处局部浓黑，以及顺原发型伸出的一至两个蛇首游线。

当前版本：`v0.1.0`（首次打包，已通过一次真实照片生成验证）

作者：`@威比 Hunter Wei.`（抖音、小红书同名）
