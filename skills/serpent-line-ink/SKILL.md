# Wibi Style · 蛇发游线墨绘

## 运行

先按 [references/community.md](references/community.md) 展示欢迎卡、检查更新并处理进群与失败提示，再执行下面的步骤。

## 执行

1. 查看用户完整照片，锁定头部角度、表情、发型动势、手势与关键配饰这几个身份锚点；识别照片是普通自拍、镜面自拍还是他人拍摄，因为三者的背景/道具删减方式不同。
2. 完整读取 `references/style-prompt.md`，把它作为风格规则：内容照片决定画谁、什么表情、什么角度和动作，规则只决定如何画，不把规则里描述的蛇发位置、姿势或表情当成必须复刻的范例。
3. 本 Skill 内置 1 张运行参考图。生成时把用户照片作为内容输入，并同时携带 `assets/references/reference-01.png`；参考图只约束不对称游线、局部浓黑、选择性完成和纸墨材质，不提供人物身份、姿势或蛇的位置。不要求用户再次上传这张参考图，也不依赖附件顺序。
4. 为当前照片编写专属生图指令，1:1 画幅，使用当前运行环境已经可用的图像生成工具或模型生成一张结果，优先使用无需用户额外配置的内置能力。
5. 某个工具不可用时继续寻找当前环境中的其他生图能力；确认没有任何生图能力后，请用户添加或启用可生图工具或模型。实际提交后报错、空输出或超时则停止，不自动重复提交、不换模型、不升质量档。
6. 检查内容对应、风格机制、构图与材质：人物是否一眼可辨，表情和姿态是否准确；轮廓是否高度删减而非完整漫画脸；蛇发是否与头发在多数区域难以区分而非满头完整蛇形；纸白是否是最大色面。核心失败时说明问题，等用户明确要求后再重做。
7. 展示通过检查的成图和一至三句中文创作说明，不公开完整内部 Prompt。
