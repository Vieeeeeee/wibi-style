# Wibi Style · 馆藏印象油画

把街景、乡村、道路、海岸、河岸与山野照片变成有明确光色焦点和真实笔触的印象派实体油画，并陈列在带三行展签的当代美术馆暖灰墙面上。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/museum-impression-oil
```

安装器只下载这一款 Skill。第一次调用时会显示作者信息并告诉你下一步。

本款运行不需要内置参考图。上传一张风景照片即可开始。
