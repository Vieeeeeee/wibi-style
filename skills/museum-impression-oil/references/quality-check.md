# 生成后检查

按顺序检查，前面的内容项优先于装饰细节。

| 检查项 | 通过标准 |
| --- | --- |
| 原片对应 | 主要场景、主体数量、方向、空间关系、季节、天气和原有光色仍可辨认 |
| 油画作品感 | 存在一个明确焦点；外围更松、更薄；冷暖笔触与亮部闪烁形成观看停留点 |
| 大形归纳 | 相邻同类景物已经合并，细节服务焦点，整体不呈现逐件描摹 |
| 厚薄层次 | 大部分区域薄而安静，厚涂集中在焦点和少量高光 |
| 展陈构图 | `1:1` 方图；画作完整、居中略偏上、保留原片比例，四周有充分墙面留白 |
| 墙面质感 | 暖珍珠灰墙连续铺满；左上柔亮、右下渐暗；细微矿物纹理自然可见 |
| 投影 | 画布右下同时具备贴边接触影和外侧柔软空气影 |
| 展签 | 只有一组三行英文；标题简短，尺寸格式合理，第三行准确写作 `Oil on canvas` |
| 空间纯净 | 没有地面、踢脚线、墙角、家具、观众、其他画作、品牌和水印 |

原片内容、画作比例或展签文字发生明显错误时判为核心失败。油画笔触局部松紧差异属于正常创作变化，只在整幅画平均、发闷或没有焦点时判为失败。
