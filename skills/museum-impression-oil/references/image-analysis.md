# 原片分析

先把照片当成内容底稿，而不是一张等待套滤镜的图。

## 锁定内容

- 识别使这张风景成立的一至两个主要视觉锚点，例如道路转折、桥、水岸、独立树、山脊、岩柱或建筑群。
- 保留原片真实存在的地点特征、主体数量、方向、相对位置和关键物件关系。
- 保留原片的横竖方向、远中近层次、视线路径和视觉重量；允许为了适配画布轻微裁切边缘。
- 季节、天气、时间、光线方向、主色、环境色和强调色由原片决定。

## 归纳画面

- 将复杂景物整理成 5–9 个有层级的大形。相邻建筑、植被、山体、岩石或道路先合并，再保留少量能确认场景的结构。
- 选择一处最能承载情绪与光线的视觉中心。焦点通常来自原片已有的亮部、转折、颜色对比或视线汇合处。
- 判断哪些轮廓需要清楚，哪些可以进入空气；焦点外的大部分区域应当更安静、更松。
- 原片信息不足的区域以概括笔触处理，不补造可识别的新物件。

最终专属生图指令要具体写出本图的内容锚点、构图路径、焦点位置和原有光色，避免照搬案例中的地点与物件。
