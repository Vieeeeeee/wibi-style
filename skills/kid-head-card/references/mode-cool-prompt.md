# 童年酷照大头 Prompt v9

## 风格定义

- 一颗完整的儿童头部悬浮在干净的浅灰白背景上，没有脖子、肩膀、衣服和身体。
- 主体是同一个人的童年版本：骨相和五官关系来自上传的成年自拍，年龄外观回到 5–8 岁。
- 全部人物统一给微笑，不分性别、不沿用原照片的表情。
- 装饰按性别分档：男孩走墨镜、银饰和冷色水钻的中性酷感；女孩走糖果色小花、心形和亮片的甜美感。
- 风格的趣味来自反差：写实高清的真实小孩脸，配上明显是塑料玩具感的、夸张的亮晶晶装饰。两种质感对撞，装饰要「假」得看得出来。
- 可爱由婴儿肥的脸颊、饱满的嘴唇和稚气的头骨比例负责，不靠放大眼睛实现；眼型永远跟着本人走。
- 画面不出现任何文字、水印和边框。

## 适用输入

- 单人正脸或近正脸的当代自拍，手机原图即可，不需要老照片。
- 成年人、青少年、儿童都能用；输入是成年人时做童年反推，输入本来就是儿童时保持年龄不变，只做风格转换。
- 长发、短发、卷发、扎发都支持；长发按下面的长发规则处理。
- 输入戴眼镜、化妆、染发、开了美颜滤镜时，先剥离滤镜与妆感回到真实骨相和天生发色；眼镜、耳饰、发饰这类实物配件反而是可取用的素材。
- 侧脸过大、遮挡大半张脸、多人合影、严重模糊的照片不适合，会丢失辨识度。

## 完整 Prompt

创作一张 1:1 高清写实儿童纯大头卡贴。用户上传的照片是唯一内容输入，负责提供人物身份和可取用的装饰素材。

**身份反推**：把照片中的人还原成 TA 5–8 岁时的样子。严格保留能认出是同一个人的骨相与五官关系——脸型轮廓、颧骨位置、眉眼间距、眼睛形状与眼距、双眼皮或单眼皮、鼻梁走向与鼻头形状、唇形与唇珠、下巴形状、耳朵形状，以及痣、酒窝、小虎牙这类个人标记。剥离原照片中的妆容、美颜滤镜、瘦脸和磨皮，回到真实骨相再重建。原照片中被手、头发或其他物体遮挡的五官，按骨相合理补全。

**年龄必须落在 5–8 岁，这是硬指标**。参照的是幼儿园大班到小学一二年级的孩子，不是小学高年级，更不是少年：

- 颅顶明显偏大、额头饱满外凸，头顶到眉毛的距离大于眉毛到下巴的距离。
- 脸颊有厚厚的婴儿肥，把颧骨轮廓完全盖住，脸的宽度接近脸的长度，整张脸偏圆。
- 下颌线柔软到几乎看不出角度，下巴短而圆，笑起来时脸颊会挤出软软的肉感。
- 鼻梁短而软、鼻头圆钝，鼻子在脸上占比很小。
- 露齿时是细小、整齐、间距均匀的乳牙，牙齿明显偏小。
- 皮肤细腻通透、绒毛可见，没有任何青春期的痕迹。

如果成品看上去像 9 岁以上，就是错的，要把脸再画圆、婴儿肥再加厚、颅顶再放大。

儿童化只改变骨骼比例和皮肤状态，不改变五官的形状本身。可爱的观感必须来自饱满的婴儿肥脸颊、柔软的下颌线、饱满的嘴唇和更大的颅顶占比，**不允许通过放大眼睛、加双眼皮或把眼睛画圆来制造可爱**。

**构图**：正方形画布，一颗头严格居中——头部的水平中轴对齐画布正中，左右留白目测等宽。整颗头像被干净抠出来贴在背景上：发丝边缘锐利分明，没有任何投影、阴影和接触面。

短发或头发不过下巴时：头部连同头发的宽度占画幅的 70%–75%。**下巴的最低点就是整个人物的最低点，下巴以下立刻就是背景**，绝对不画脖子、喉咙、下颌以下的任何皮肤、锁骨、肩膀、衣领、衣服、手或身体。

长发时（头发垂过下巴）：把「头 + 全部头发」当作一个整体来安排，**整体缩小**，让头顶最高的一根飞发和最低的一缕发梢都完整落在画面内，四周留出干净的空白，任何一处头发都不许被画布边缘切到。下巴以下的区域**只允许出现头发**；**头发之间的所有空隙直接透出浅灰白背景，绝对不透出脖子、喉咙、锁骨或任何皮肤**，也不画肩膀、衣领、衣服、手和身体。整体仍然是一张干净的抠图贴纸，不是半身肖像。

头部保持端正的正面角度，不做低头、抬头、后仰或转头的动作。

**眼睛**：眼型完全照搬原照片本人的眼睛，这是辨识度的第一来源——眼裂的长短和弧度、单眼皮还是双眼皮、内眼角和外眼角的高低走向、上挑还是下垂、眼睛在脸上的相对大小，全部原样保留，只按儿童的头骨比例整体放置。

- 细长眼保持细长，单眼皮保持单眼皮，上挑眼保持上挑。
- **绝对不要改成又圆又大的通用娃娃眼，不要擅自加双眼皮，不要把细长眼画圆，不要为了可爱而放大眼睛。**
- 视线稳稳地直视镜头，瞳孔清晰，有干净的眼神光。

**表情**：不管原照片里这个人是什么表情，成品一律给微笑，男女相同。

- 嘴角自然向上扬起，露出轻松的浅笑，微微露出一点点细小整齐的上排乳牙；不要抿嘴不笑，也不要咧到耳根的夸张大笑。
- 眼睛因为笑而微微弯起，下眼睑轻轻上提，眼神清亮，但眼型仍然保持本人的形状。
- 脸颊因为笑而鼓起来，苹果肌抬高，婴儿肥更明显。
- 两侧嘴角和眉毛允许有一点点幅度极小的高低差，让笑容自然，不是左右完全对称的僵硬假笑。

整体效果：一个被逗笑了的小孩，轻松、真诚、好亲近。不要歪头卖萌，不要挤眉弄眼，不要证件照式的僵硬表情。

**发型**：这一条和装饰同等重要，不要因为要加装饰就把头发画短、画少。

沿用原照片的发型神韵——长度、轮廓、蓬松度、分缝与走向、发质的直卷粗细都跟着原图走，按儿童的头骨比例和更细软的发丝重新长一遍，神似即可。原图是卷发就必须是卷发，是扎发就保留扎发的形式，是中长发就不许剪成短发。

短发时是那种「快该去剪了」的长度，不是刚理完的短发：额前的头发自然垂下来、发梢落在眉毛上方约一指宽的位置，把额头的上半部分遮住；两侧的头发向下盖住耳朵的上半部分。**绝对不要寸头、板寸、圆寸、毛寸或任何贴着头皮的超短发型，也不要露出光洁的整个额头。**

头顶蓬起有体积，发流有方向，能看出头发是有重量、会被风吹动的。发丝根根分明有光泽，轮廓外沿保留自然的碎发和飞发，毛躁不服帖，别修成光滑服帖的发块。

**发色回到这个人的天生发色**（东亚面孔默认黑色或深棕），原照片中的漂发、染发、挑染一律不带入，因为小孩不会染发。

**装饰**：装饰要夸张、亮晶晶，是这张图的趣味来源，要一眼看得见，不能小到需要找。它们必须明显是贴上去的塑料玩具质感，和写实的皮肤形成质感反差。**先按人物的性别气质选档，不要混用。**

先处理原照片里的实物配件：本人佩戴了耳环、耳钉、眼镜、墨镜、发夹、发带、帽子、头巾时，把其中 1–3 件带进成品，**材质、颜色、款式一并保留**——金色的保持金色、粗圈的保持粗圈、圆框的保持圆框、棒球帽保持棒球帽，只按儿童尺寸缩小，并可以做得更童趣、更夸张一点。

男孩档，走中性的酷感，**不要成片的糖果色花朵**：

- 一副黑色墨镜歪着架在头顶偏一侧，明显倾斜、不端正，镜腿压进头发里。原照片本人已经戴了眼镜或墨镜时，直接沿用原款式架在头顶或正常戴着。
- 双耳银色耳环与耳骨钉 2–3 枚，其中一只可挂极小的坠饰。
- 8–15 粒大小不一的水钻闪片和星芒，颜色限定在无色、银、白、冰蓝、黑这类中性冷色，另可加 1–2 枚微型方块标签贴或小星星。
- 最多允许 1 朵小花做点睛，不要多。

女孩档，走糖果色的甜美感：

- 2–4 朵糖果色小花（粉红、鹅黄、薄荷绿、天蓝），另加心形、星星、亮片这类可爱造型。
- 8–15 粒大小不一的彩色水钻和亮片，粉嫩色系，可以密集成簇。
- 银色或原图同色的小耳饰，发夹发绳可做成塑料小花或小星星。

两档共同的摆放规则：装饰**不对称地簇集**在一侧脸颊外围、太阳穴和眉尾，另一侧只零星几粒，允许少量落在头发、耳廓和配件上。装饰要有明显的立体感和高光反射，像真的水钻和塑料贴纸贴在脸上，不是画上去的图案。眼睛、眉毛、鼻子和嘴巴必须完全无遮挡。

**背景**：单一纯净的浅灰白底，接近 `#EAEBED`，完全平整，无渐变、无纹理、无阴影、无投影、无装饰。人物靠自身明度和色相与背景分离，不加白边和描边。

**光影与质感**：明亮柔和的高调棚拍布光，正面主光加轻微侧向补光，脸上没有硬阴影。清亮的眼神光，暖润健康的肤色，自然红润的面颊，保留毛孔、绒毛、碎发和极细的现代摄影纹理。整体清透、通亮、锐利，无灰雾、无泛黄、无颗粒、无老照片感，也不做磨皮、不做蜡像皮肤、不做 3D 渲染或插画化。

**成品**：只输出单幅 1:1 成品。不出现任何文字、字母、数字、标签、水印、logo、边框、拼图、分屏和对比排版。
