# 钻牙萌娃大头 Prompt v9

## 风格定义

- 将单人儿童老照片转译成高清写实的萌感纯大头贴片：画面只保留脸、头发、帽子与头部配饰，下缘沿下巴和头发自然闭合，干净悬浮在纯白底上，像一枚独立的头像卡贴。
- 人物身份、年龄感、脸型、五官、神态、发型与头部配饰保持可辨认；只对头部比例、画质和笑容做风格化提升。
- 核心趣味点是露齿笑容中整颗牙面铺满细密钻石的闪耀感；只有原片清楚露出牙齿时才添加钻牙，原片闭嘴或几乎不露齿时保持原本嘴型和表情，不强行造出牙齿。D 背景另有少量彩色蜡笔手绘小星星，整体干净、轻松、可爱。
- 原照片只负责提供人物身份与头部特征，不负责定义成品的年代、曝光和色调。整体必须重拍式重建为明亮、光鲜、可爱的现代儿童棚拍大头卡贴：高调柔光、清亮眼神光、暖润健康肤色、自然红润面颊、干净有光泽的深色头发、鲜活颜色与通透层次。成品要与暗沉老照片形成明显反差，不能只是清晰化、降噪或修复旧照。

## 适用输入

- 适合单人儿童老照片，脸部与头发大致可辨；正面或轻微侧面、已有笑容的照片最容易得到稳定结果。
- 原片的帽子、发辫、发饰、耳饰等头部特征属于身份锚点，需保持形状、位置和基本颜色。
- 模糊、褪色、颗粒重或有轻微折痕的老照片可以使用，但重建后仍要看得出是原来的小孩。

## 完整 Prompt

创作一张 1:1 的高清写实儿童纯大头卡贴，将内容输入中的老照片人物重新拍摄式地转换为明亮、光鲜、可爱的现代高清儿童棚拍大头；原片有明显露齿笑容时，再将每颗可见牙齿做成精致闪耀的满钻牙。成品只有一张单幅画面，主体只有一颗完整的头。背景从五种方案中明确选择一种；用户未指定彩色背景时固定使用默认白色，不自行改用其他颜色。D 方案使用干净留白加少量蜡笔手绘小星星。

【附件角色】
附件中只上传一张需要转换的儿童老照片。这张内容输入决定画面中是哪个小孩、长什么样；所有风格规则都由本 Prompt 的文字定义，正式测试不携带风格参考图。

【内容锚点】
先识别原片中小孩的脸型、眼睛、鼻子、嘴型、肤色、年龄感和标志性神态，再识别发型、发际线、刘海、发辫、马尾、发揪、帽子、发饰、耳饰等头部特征。这些身份特征在现代高清重建中保持稳定，让家人仍能一眼认出原照中的小孩。原片的暗沉曝光、昏黄室内光、褪色、棕灰色调、旧闪光灯光感、粗颗粒和年代感不属于身份特征，不得保留。原片画框内完整可见的头发、发辫、发揪与配饰必须完整进入成品，不得中途消失或无故截断；只有原片本身已经出框的部分，才可沿原有方向自然出框。

【构图】
使用正面、居中的独立大头贴片构图。脸部位于画面正中央，眼神面向镜头；在完整容纳原片框内所有可见头发、发辫、发揪、帽子和头部配饰的前提下，将整颗头尽可能放大，四周只保留必要的背景安全距离。若 82%–90% 的高度会截断头发或配饰，则自动缩小头部，优先保证轮廓完整。头部下缘紧贴下巴轮廓和发丝轮廓自然闭合；发辫可以沿脸部两侧完整垂落，但大头下方仍只有当前选定背景。整个主体像从照片中精准取出的完整头像卡贴，轮廓干净、完整、无多余结构。

【比例与神态】
保持真实儿童的骨相和年龄感，头部与面颊做轻微圆润化，让大头比例显得更萌、更亲和，同时仍然像本人。保持原片的嘴部开合程度和真实表情：原片已经露齿微笑或大笑时，保留它的嘴型和露齿程度；原片闭嘴、抿嘴或只露出极少牙齿时，保持该表情，不扩大嘴巴，不额外造齿。眼睛清亮有神并带自然眼神光，面颊有健康红润和儿童般鲜活感。

【钻牙效果】
先判断原片是否有清楚可见的露齿笑容。有露齿笑容时，将每颗可见牙齿的正面做成连续的满钻牙：在每颗牙面上密集铺满多颗极小、精细切割的无色钻石，钻石紧密相邻，覆盖整个可见牙面，形成完整、华丽、珠宝般的钻牙排列，不是每颗牙中间只放一粒钻，也不是牙钉、牙套或牙箍。钻面有清晰的细小切面、银白高光与 2–4 处克制的小星芒，闪耀、亮丽、很可爱，同时保持嘴唇、牙龈、齿列和口腔结构自然。原片闭嘴或几乎不露齿时，完全跳过钻牙效果，保持自然嘴唇和原始表情。

【色彩、材质与光影】
把输入当作“这个孩子是谁”的身份资料，并以当代高端儿童摄影棚重新拍摄的标准重建人像。成品必须显著摆脱老照片观感：清除昏黄室内光、棕灰色罩、褪色、暗角、沉闷阴影、旧闪光灯痕迹、粗重胶片颗粒和年代感；不能停留在锐化、降噪、上色或旧照修复的程度。

使用明亮的大面积正面柔光作为主光，配合轻微侧上方塑形光与干净补光，让额头、鼻梁、面颊和下巴有柔和立体感。整体采用现代儿童商业摄影的高调曝光：脸部明亮通透，眼睛有清晰自然眼神光，肤色是健康温暖的自然黄粉色，面颊和嘴唇鲜活红润；黑发或深色头发深邃、干净并带自然光泽，发带和配饰颜色清晰明快。提高中间调亮度、色彩纯净度和适量微对比，使人物看起来光鲜亮丽、可爱、有精神，同时高光保留细节、不过曝、不产生直打闪光的油亮白斑。

皮肤保留细小毛孔、绒毛、自然色差和柔和阴影，发丝保留真实细节与高光走向。只加入极细、低密度的现代数字摄影纹理，用来避免塑料皮肤；纹理不能呈现旧胶片、灰尘、划痕或怀旧感。保持钻石切面透亮、银白高光清晰。

【背景选项】
一次只使用下列一种背景，不把多种方案拼在同一张图中。人物的脸、头发、帽子、发饰和钻牙保持写实摄影质感；背景只负责颜色和平面图形，不向人物内部延伸。

1. **默认白色**：整片均匀、干净、没有明显颜色倾向的摄影白，使用非常轻微的暖调，接近 `#FAF8F3`；视觉上仍然明确是白底，避免冷蓝死白，也不做成明显米黄或奶油色。没有渐变、纹理、阴影、光晕或地面。用户未明确选择彩色背景时固定使用本项。
2. **复古大波点**：使用高饱和底色加大颗均匀圆点，圆点整齐重复、边缘清晰、大小统一，保留大面积干净色块。优先使用粉红底配乳白点、蓝绿底配浅黄点，或象牙白底配深色点；根据人物的头发、帽子和发饰避开相近颜色。
3. **柔和双色渐变**：使用两种明亮柔和的鲜艳色做平滑、干净、无纹理的大面积渐变，例如粉红到杏黄、薄荷蓝到淡紫、珊瑚橙到桃粉。渐变只提供色彩氛围，不出现光晕、日落、风景或具体物件。
4. **蜡笔手绘小星星**：保持干净的暖白背景底，接近 `#FAF8F3`，不做分区、渐变或复杂纹理。加入少量彩色蜡笔手绘小星星，颜色可用明黄、粉红、薄荷绿、天蓝、淡紫和橙黄；星星大小有变化，轮廓略微不规则，带轻微蜡笔涂抹纹理，但整体清爽可爱。星星疏朗分布在背景四周，允许少量星星落在头发、耳朵或脸部外围，形成轻微表面叠加感；眼睛、眉毛、鼻子、嘴巴、牙齿、耳饰和其他重要身份特征区域必须完全无遮挡并保留干净留白。不要文字、笑脸、涂鸦人物、太阳、云朵、彩带、贴纸边框或其他物件，也不要带入参考图中的人物、发型、眼镜、首饰、棒棒糖或妆容。
5. **柔粉纯色**：整片使用均匀的 `#F3CCD1`（RGB 243, 204, 209），呈现明亮、温柔、略带灰度的樱花淡粉。无渐变、纹理、阴影、光晕、地面或空间感，不漂成高饱和玫粉、紫粉、肉色或米色。该色值来自用户参考图的干净背景区域；参考中的人物、发型、犄角、首饰、妆容、棒棒糖、表情和光影全部忽略，不进入生成输入或成品。

【背景选择流程】
第一次生成前先给用户五个选项：A 默认白色（推荐）、B 复古大波点、C 柔和双色渐变、D 蜡笔手绘小星星、E 柔粉纯色 `#F3CCD1`。用户明确选择时执行对应方案；用户说“默认”“都行”“你决定”，或只说生成而没有提出彩色背景时，一律使用 A 默认白色，不根据人物颜色自动改选彩色背景。

【人物与背景分离】
先通过配色建立轮廓反差：人物头发、帽子或发饰与背景的明度和色相至少有一项明显不同。若轮廓仍与背景混在一起，才沿完整头部、头发、发辫、帽子与头部配饰外轮廓添加一圈均匀细白边，白边宽度约为画面宽度的 0.8%–1.2%，像精心切割的头像贴纸。默认白色背景下不加白边；彩色背景也优先不加，只在视觉分离失败时启用。

【完成度】
成品达到当代高端儿童摄影棚、儿童杂志头像和珠宝编辑摄影的清晰度，脸部辨识度高，构图简洁，质感真实，明亮光鲜、可爱、俏皮、略带夸张。一眼认得出原照片中的孩子，同时一眼看得出这是重新拍摄的现代儿童人像，而不是修复清晰后的老照片。视觉形式是一颗精心摄影后制成的写实大头卡贴，主体轮廓完整，周围是当前选定的干净背景。

【必要边界】
只输出单幅完整成品；不做上下对比、分屏、拼贴或文字版式。主体严格只包含人物的头、头发与头部配饰；画面内完全没有脖子、肩膀、锁骨、胸口、手臂、躯干或任何服装部分，下巴下方直接是当前选定的背景，不出现颈部截面或阴影。头发与头部配饰遵守“原图框内可见就完整保留，原图已出框才允许裁切”的边界。钻石只在原片明显露齿时贴合并铺满可见牙面，不延伸到嘴唇、牙龈、皮肤或脸部其他区域；闭嘴时不添加钻石，不改变嘴部开合。参考图中的波普假发、夸张彩妆、眼周图形、星星、指甲、手、服装、植物剪影和人物涂鸦全部属于示例内容，不是本风格规则，不进入成品。
