# 红蓝手绘时装 Prompt v99

将用户上传的单人真实照片重新设计成日式时装漫画海报，默认画幅为 3:4 竖版；用户指定其他比例时按所选画幅。用户照片是内容与身份依据；系统随附的风格参考只定义漫画造型、夸张衣身比例、轻薄墨线和红蓝平涂的处理方式。人物从外轮廓到五官都完成鲜明的二维角色化。

风格语言：graphic fashion manga（图形化时装漫画）、stylized character design（风格化角色设计）、elongated fashion silhouette（舒展的时装剪影）、exaggerated garment shapes（夸张服装块形）、selective ink linework（有取舍的墨线）、flat spot-color print（平面专色印刷）、hand-cut poster lettering（手刻海报字）。气质轻巧、松弛、略带古怪；轮廓的个性与大色面的节奏优先，细节只服务于辨识和动作。

真实照片提供身份与内容：抓住脸型特征、发型外轮廓、神态和动作等少量识别锚点，保留原有穿搭类别、层次、物件以及接触关系。允许重新设计头身比例、衣服体积和服装配色。人物仍属于照片中的人，参考只提供造型语言；仅绘制照片可见的身体与物件。

脸重构为简洁的漫画面形，下颌与面颊用明确转折概括；眉眼按原神态变成有表现力的线与小色块，鼻子一笔带过，嘴保留原来的开合和情绪。脸颊、鼻梁与嘴唇采用平面概括。头发并成几束有尖角或弧线的整体块形，以外轮廓和少量内部走向线保留发型，亮部是整块留白。

沿原动作拉开身体的长短、宽窄节奏；可见四肢以修长、略有折角的简洁线面表达。强化原有衣服的宽松或贴身特征，宽松处合并为蓬起的大块轮廓，与较窄的身体部位形成鲜明反差；褶皱只在关节转折和衣料汇聚处留下疏落方向线。手用简洁漫画轮廓保留原手势、数量与接触位置。

墨黑 #02030B 的手绘线有提按、顿挫和自然不齐，轮廓明确，内部疏朗。服装内部以连续、平整的大色面为主，暗部合并为少量整体色块。肤色保持照片的深浅印象，表面平涂；体积由形状与遮挡表达。纸纹和印色浓淡很轻。

浅灰米白 #ECEDE5 铺满纸底并包围人物。暖红 #E9444B 落在人物原有主要衣物的大色面上，与红色标题呼应；灰蓝 #5296BD 用于少量局部与第二行标题，形成红多蓝少的主次。肤色和发色保留身份特征，其余颜色收敛到纸白、墨黑与这组红蓝。

默认采用3:4竖版画布，人物占据上方约三分之二，标题组落在下方；纸白围绕人物与字组形成疏朗呼吸。用户明确选择其他画幅时，以实际选择为准，协调人物与字组的上下尺度。根据照片的全身或半身景别，协调人物与两行标题的尺度，保留可见动作和服装轮廓；仅呈现原照片可见的身体范围。背景归纳为纸底，仅当动作需要支撑时留下最小接触面，环境退为从属。人物、小字及主标题全部落在实际画布内。

文字是根据当前用户照片单独设计的海报文案。先观察照片里确实可见的动作、穿搭轮廓、物件或情绪，从中选一个最明确的主题；在绘制前确定一组彼此呼应、拼写正确的短文案。全图仅有三组文字：两行主标题算一组、标题正上方的引题算一组、头肩旁的小注算一组；其余位置留白。风格参考图和旧案例中的既有字样只供观察手绘字形，不作为本次画面的文案。

主标题分两行，优先使用简短、自然的英文词组；两行合起来表达同一主题，并能由照片里的可见内容支持。第一行用暖红 #E9444B，第二行用灰蓝 #5296BD。每行控制在一至两个短词，宽度随字数自然变化，保证整组在实际画布内完整可读。两行都是醒目的手绘块状字，每个字母独立画出，笔画宽窄、转角、字距和高低略有差异，轮廓轻微毛边，内部保持完整印色。字组在人物下方居中；人物下缘可以轻遮首行大字的上沿，但文字仍可辨读。

两行大标题正上方同一处写一句墨黑手写引题，用两至五个常用英文词补充同一主题。字距舒展，基线自然起伏，像作者写在纸上的小注；这一句只写一次，不拆到人物左右两侧。

人物旁另写一句一至四个常用英文词的小注，回应人物的动作或状态，不重复主标题。放在头肩附近较空的一侧，用小号墨黑随手字，可自然折成两行，字号略小于引题，笔画细而有停顿；与人物留出距离。

三处文字应有真实含义且相互呼应，取材只限照片可见信息。照片无法支持的姓名、品牌、地点、日期、职业、事件和故事不写入；线索少时用对可见姿态或衣着的简短描述，不编造背景。画面不照搬参考图或旧案例的标题、品牌字，也不添加无关符号、乱码、伪英文和重复文案。若用户明确指定主标题、引题或小注，逐项优先使用指定原文的语言、大小写和标点，仅为未指定项按照片设计文字；用户要求删去某项时留白。画面只呈现最终选定文案，构思过程留在指令中。

成品应一眼读到经过重新设计的漫画人物、夸张衣形和大色块。排除写实人体描摹、逐根发丝、密集明暗排线、立体皮肤渲染、磨损噪点和额外装饰符号。
