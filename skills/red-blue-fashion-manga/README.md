# Wibi Style · 红蓝手绘时装

适合单人穿搭照、街拍和动作清楚的半身或全身人像。默认生成 3:4 竖版海报，并根据照片中的动作、穿搭或物件设计文字；用户也可指定比例和文字。

当前版本：`v1.0.1`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

以下六张是早期 1:1 方图与品牌文案的画风展示。当前版本默认输出 3:4 竖版，并按上传照片的可见内容设计海报文字；用户也可以指定比例和文字。

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/red-blue-fashion-manga
```

安装器只下载这一款 Skill。装完不用做别的，第一次调用时它会自己打招呼并告诉你下一步。

本款运行需要的参考图：`1` 张。需要时已放在 Skill 自己的 `assets/references/` 中，会随本款一起安装；用户无需再次上传。
