# 第一段：先看懂这张照片

生成之前先把原片看完，这一段不需要展示给用户。

### 1. 认清内容

- 这是什么菜？主要食材、酱汁、颜色、有没有蒸汽和油光。
- 器皿是什么？盘碗杯的形状、材质、釉色、花纹、碗沿的字。这些是识别度，必须原样带走。
- 桌上一共有几件东西？哪些是食物，哪些是餐具，哪些是垃圾（手机、纸巾、二维码牌、账单、包、椅子、路人）。

### 2. 定主角和配角

一张图只能有一个主角，就是最有食欲、最有辨识度的那道菜。

配角留 2 到 4 件，选的标准是**能帮画面建立层次或呼应颜色**：另一道菜、一杯饮料、一个蘸料碟、一双筷子、一瓶酒。超过这个数就开始堆积，红底的呼吸感会没。

明确删掉：人、手、手机、纸巾、消毒餐具包装、二维码立牌、菜单、账单、椅子、地板、其他桌、店内招牌和一切文字招贴。原片器皿上本来就有的花纹和文字保留。

### 3. 判断视角

看原片是俯拍、45 度还是平视，成片保持同一视角。这一条比构图更硬：视角一变，菜的样子就变了，用户会觉得不是自己那顿饭。

- 俯拍原片 → 俯拍成片，桌面就是整个背景，红色铺满。
- 45 度原片 → 45 度成片，桌面和背景连成一体，不要出现地平线、墙面、桌沿。
- 平视原片 → 平视成片，背景是一整片纯红，桌面与背景无缝。

### 4. 决定留白落在哪一侧

看主角在原片里偏哪边、盘子的开口和酱汁的走向朝哪边，把留白放在对角或对侧。

3:4 竖构图里通常这样落位：主角压在下半部或某一侧下方，留白吃掉上方或对侧那一大块。留白不是空着没用，是给红色一块完整、干净、不被打断的面积。

### 5. 挑出谁去出框

至少一件器皿要被画面边缘大胆切掉，这是这个风格的骨架。选那个**被切掉一半也不影响识别**的：一杯饮料只留半杯、一个大盘子只进来三分之二、一瓶酒只露瓶身。

不要切主角的关键部位。主角的菜可以被切掉一点边，但整道菜的完整感要在。
