# 第二段：把它拼成一张成片

### 固定风格（每张都成立）

**背景**：纯正复古印刷红——正红偏暖，接近旧杂志四色印刷的品红加黄，不是番茄红、不是酒红、不是玫红。桌面和背景是同一块红，平整、无纹理、无渐变、无暗角。红是这个风格的身份，不要换色，用户主动要求换背景色时才换。

**投影**：短、方向统一、边缘略实。物体稳稳压在桌面上，有明确接触点，不悬浮、不漂浮、不加倒影。投影里可以带一点红底的颜色，不要纯黑。

**光**：柔和棚拍光或轻微直闪，从一侧偏上打。食物形体明确，高光在油光、汤面、玻璃和金属上。不要戏剧性侧逆光，不要大面积暗部。

**颜色**：食物本身的颜色饱和、鲜明、受控，跟红底拉开对比。绿的更绿一点，黄的更黄一点，但不能塑料。整体带一点旧油墨的偏色，像放了三十年的印刷品。

**质感**：轻微胶片颗粒、细密印刷网点、旧杂志扫描感、略微褪色的油墨。绝不做旧到发脏、发霉、划痕、折角。

**解析力（这一条决定像不像复古）**：旧杂志的复古感来自**镜头解析力有限、印刷网点把高频细节吃掉**，不是滤镜色。所以画面必须是**柔的**：边缘略微发软，细节到网点为止，看得出是印刷品不是屏幕截图。

这一条最容易被写反。不要在指令里写「轮廓清晰」「锐利」「高清」「4K」「纤毫毕现」——这些词会把画面推成电商产品图或 CG 渲染，一眼就不复古了。要写的是柔和的胶片光学、有限的印刷解析力、被网点吞掉的细节。

「柔」指光学上的柔，不是拍糊。形体、食材种类、器皿花纹都要认得出来，只是边缘不是刀锋。

### 二次构图怎么做

按第一段的判断重新摆这一桌，不是把原片抠出来贴到红底上：

- 主角放在偏心位置，占画面显眼但不铺满的一块。
- 配角按前中后分层，允许互相遮挡一点，形成自然的深浅关系。
- 至少一件器皿出框。
- 留白留成一整块完整的红。
- 器皿之间留出干净的红色缝隙，不要挤在一起。

摆完自检一句：把这张图放进旧杂志的整版广告里，它撑得住吗？撑不住通常是因为主角太小、太居中，或者东西太多。

### 写当前照片的生图指令

把上面两段的判断，编成一段只服务于这张照片的指令。**顺序很重要：内容锁定必须排在第一位，风格描述排后面。** 风格那几段写得越细越有分量，一旦放前面就会盖过内容，模型开始自作主张重新设计摆盘。

1. 明确这是图生图，用户照片是内容来源，内置参考图只提供风格。
2. **内容锁定，放最前面。** 这道菜是什么、必须保留哪些识别特征（食材、酱汁、器皿形状、花纹、碗沿的字）。写死一句「这是同一顿饭的重新拍摄，不是重新设计的样片，不许重新摆盘」。
3. 本次视角、主角位置、留白落在哪一侧、谁出框、留哪几件配角、删掉什么。
4. 固定风格那几段：红底、投影、光、颜色、质感、解析力。解析力那段必须写进去，别只写颗粒和网点。
5. 3:4 竖构图。

写内容锁定时，**对容易被改的地方点名给数**，别只说「保留原样」：

- 数量点名：「大虾只有三到四只，不要加到六只以上，不要沿盘边摆成一圈」。
- 器皿形状点名：「圆形黑铁盘架在圆形木托盘上，不是带长柄的煎锅，不是多边形木板」。
- 主食形态点名：「白米饭是随意盛在盘里的一小堆，不要捏成规整的半球或饭团」。
- 架状器皿点名：「烤网直接放在桌面上，底下不加盘子、不加托盘、不加垫布」。
- 最后补一句：「保留原本那种随意的、真实吃饭的样子，不做精致摆盘，不做对称排列」。

反过来也别写过头。描述某样东西时加「要有分明的米粒感」这类精修形容，会反过来诱导模型去重做那个部位。要的是「保持原样」，不是「做得更好」。

不要把这段指令展示给用户。

### 执行生成

使用当前运行环境已经可用的图像生成工具或模型生成一张结果，优先使用无需用户额外配置的内置能力。某个工具不可用时继续寻找环境中的其他生图能力；确认没有任何生图能力后，请用户添加或启用可生图的工具或模型。实际提交后报错、空输出或超时则停止，说明情况，不自动重复提交。

选模型时有两条经验，环境里有多个可选时按这个挑：

- **优先 GPT 系图像模型。** 实测同一张原片、同一段指令，它出的图天生更接近旧印刷品——边缘本来就软，颗粒和褪色油墨是自带的，而且对「不要重新摆盘」这类内容约束更听话。别的模型出的往往是干净数码图，复古感全靠后期补。没有 GPT 系可用时用环境里的其他模型，收尾脚本会自动补足差额。
- **确认走的是能吃图的端点。** 这个风格是图生图，用户照片是内容来源。有些工具在 OpenAI 兼容接口上把图像模型接到了纯文生图端点（`/v1/images/generations`），一旦带图就**静默降级换成另一个模型**，日志不显眼很容易看不出来。带图必须走图像编辑端点（`/v1/images/edits`）。出图后如果发现内容忠实度突然变差，先回头确认实际用的是不是你以为的那个模型。

画幅：目标是 3:4。工具支持就直接指定；只提供 1:1 / 3:2 / 2:3 的（GPT 系常见）选 2:3 再居中裁成 3:4，裁掉的是上下留白，不会伤到主体。

### 收尾：印刷质感

生成成功后，对结果运行一次收尾脚本，再展示给用户：

```bash
python3 {baseDir}/scripts/vintage_finish.py 生成结果路径
```

这一步做的是解析力和动态范围，不动颜色：降解析力、光学柔化、加印刷网点与胶片颗粒、把暗部抬起高光压住。

为什么必须有这一步：图像模型出的图默认太锐，**光靠文字指令压不下来**——实测把指令里所有「清晰、锐利」换成柔化描述，锐度只降了一半，离目标还差一个数量级。文字负责风格方向，这一步负责把质感钉死。

强度不用管，脚本自己量自己调：先量当前图的锐度，二分搜一个能落进目标区间的强度。不同模型出图锐度差很多，写死一个数换个模型就废。

- 输出 `VINTAGE_FINISH_OK` 时，展示收尾后的图片，不展示收尾前那张。
- 输出 `VINTAGE_FINISH_SKIPPED reason=already_soft` 时，说明这张本来就够柔，直接展示原图。同一张图不要重复收尾。
- 输出 `VINTAGE_FINISH_SKIPPED reason=pillow_not_installed` 时，直接展示原始生成结果，顺带一句可以装 Pillow 拿到更足的印刷质感。不要因为这一步失败就重新生成。
- 用户说太糊时用 `--strength 0.3` 重跑收尾前的原图，说复古味不够时用 `--strength 0.9`。这是重跑收尾，不是重新生图，不花生成费用。
