# Wibi Style · 复古餐桌杂志

把随手拍的餐桌照片重新构图成红底复古杂志美食静物。适合餐厅打卡照、家常菜、外卖照——整桌或单盘都可以，能看清菜和器皿就够。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 它做什么

不是给照片换个底色，而是重做一遍构图：先看懂这一桌谁是主角、留白该放哪一侧、哪些器皿值得被画面边缘切掉，再把杂乱的餐厅环境换成一整块纯正的复古印刷红，加上旧杂志扫描的颗粒与网点。菜品、酱汁、器皿花纹全部保留，看图的人能认出这就是自己吃的那顿。

默认输出 3:4 竖构图。

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/retro-table-print
```

安装器只下载这一款 Skill。装完不用做别的，第一次调用时它会自己打招呼并告诉你下一步。

本款运行需要的参考图：`2` 张，已放在 Skill 自己的 `assets/references/` 中，会随本款一起安装，用户无需再次上传。
