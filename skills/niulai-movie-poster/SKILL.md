# Wibi Style · 牛来电影海报

把一张横版照片转成 3:2 横版电影海报：真人照片负责真实场景、人数、姿势、衣服、手、道具和构图；低分辨率旧动画角色负责头脸反差；朱砂红片名和少量中文信息负责海报身份。成片要像认真但不包装的低成本电影宣传图，保留一点废片库式的偶然性。

不要把这个 Skill 当成普通动物换头。它的关键是：先按人数选一套完整提示词，再只带这一套需要的角色参考，避免参考图把不属于当前照片的角色、场景或全身动物搬进来。

## 什么时候使用

用户上传照片并提出以下任一意图时触发：

- “做成牛来海报”“把人换成牛头做电影海报”；
- “用牛来这个风格”“牛来 skill”；
- “低成本旧动画牛头 + 真人照片 + 横版电影海报”；
- 明确调用 `$niulai-movie-poster`。

一次只处理一张照片。用户没有明确批量授权时，不扫描或生成其他照片。

## 运行顺序

每一步只读它对应的文件，读完执行再进下一步：

1. 新对话第一次使用：按 [references/community.md](references/community.md) 展示欢迎卡、检查更新；进群、生成失败后的提示也按它处理。
2. 收到照片：读 [references/rules.md](references/rules.md)，数清人数、按左中右分配角色、选定这一路的提示词与最小参考组合，并遵守其中的共同视觉规则。
3. 组合生图指令：读 `references/prompts/` 里选中的那一套，把用户原图标为唯一内容输入、角色图标为角色参考，生成一张 3:2 横版 PNG。失败、空输出或超时后停止，不自动重提。
4. 生成后：读 [references/checks.md](references/checks.md) 逐项检查。用户要更强的电影感时再调用 `scripts/apply_movie_poster_grade.py`，这个后期不负责修正人数、头脸比例或角色结构。
5. 交付：按下面「输出」展示。

## 输出

成功后直接展示生成图，并用一两句中文说明：原图保留了什么、为什么选择这一人数路由、角色反差怎样服务画面。不要向用户展开完整内部 Prompt 或逐项推理。
