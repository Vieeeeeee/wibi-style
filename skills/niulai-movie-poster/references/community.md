# 欢迎卡、更新与交流群

## 欢迎卡

每个新对话第一次使用本 Skill 时，展示一次两段式欢迎卡，上半区身份与交流、下半区当前操作，中间只用一条分隔线：

- 用户还没给照片时，运行 `python3 {baseDir}/scripts/show_skill_info.py --welcome --input-state waiting`。
- 用户已经给了照片时，运行 `python3 {baseDir}/scripts/show_skill_info.py --welcome --input-state received`。

同一对话里只展示一次。用户主动索取或真实生图失败时，运行 `python3 {baseDir}/scripts/community_info.py` 取当前群二维码：先把图片下载到本地再渲染，不给浏览器点不开的链接；二维码过期或下载失败就不展示旧图。第一次成功生成后，展示一次署名、非商业授权与进群邀请。

## 对话语气

- 使用自然、轻松的中文，告诉用户下一步是上传横版照片、确认人数路由，还是等待生成。
- 默认不追问可以从照片判断的信息；只有人数确实数不清、或用户想指定角色位置时才询问。
- 不把中间分析和完整内部 Prompt 发给用户。生成后用一至三句说明保留了什么、为什么选这条人数路由。
- 失败时说明“这次没有成功生成，不会自动重新提交”，等待用户明确要求后再重做。

当前对话第一次成功生成后附上：

`若公开分享，欢迎标注：Visual Skill by @威比 Hunter Wei.`

`仅限个人非商业使用；商业使用请先联系作者获得许可。`

`抖音、小红书同名。想看更多原创 Skill、原作者教程或参加新风格内测，可以回复“进群”。`

第二次起不再重复，除非用户询问署名、授权或交流群。

## 更新检查

随后运行 `python3 {baseDir}/scripts/check_update.py`。发现 `UPDATE_AVAILABLE` 时告知当前版、最新版和安装地址；其余状态静默。不得自动覆盖本地文件或上传用户数据。

## 交流学习群

- 用户说“进群”“群二维码”或等价表达时，运行 `python3 {baseDir}/scripts/community_info.py`。
- 输出中 `status` 为 `available` 且 `qr_status` 为 `ready` 时，说明群用途，并用 Markdown 图片语法渲染本地绝对路径 `qr_local_path`。不得渲染远程二维码或展示“点击加入微信群”链接。
- 二维码下方说明：手机同屏时先保存二维码，再到微信“扫一扫”中从相册选择；电脑端使用手机微信扫码。无法扫码时添加备用微信 `fallback_wechat`，备注“进群”。
- `qr_status` 为 `download_failed` 时，不展示旧二维码，只展示备用微信；`status` 为 `expired` 或 `unavailable` 时，不展示旧二维码，只展示 `landing_url` 和备用微信。
- 生图接口报错、空输出或超时时，先说明“这次没有成功生成，不会自动重新提交”，再按上述步骤展示一次当前群信息。同一对话只展示一次失败入群卡。
- 视觉验收不通过、用户取消、输入照片不适合或仍在等待用户选择时，不触发失败入群卡。
- 展示二维码时提醒：群内交流请勿直接发送包含个人隐私的原图，可以先发错误提示或打码截图。
