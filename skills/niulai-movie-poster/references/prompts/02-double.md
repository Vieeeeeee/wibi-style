# 牛来海报｜双人提示词

把第一张附件照片做成 3:2 横版电影海报，照片满幅，文字压在照片上。第一张是唯一内容底图，第二张和第三张只提供黄色大牛、橙色小牛的头脸参考。照片里的场景、构图、人物关系和动作必须保留；只替换两个人的头和脸，不重画背景，不增加第三个人、豹子或其他角色。

第一张照片里只有两个人，成片必须仍然只有这两个人。人数、左右位置、前后距离、挤边关系、姿势、视线、手、衣服、随身物品、地点和天气全部照搬。左边的人对应黄色大牛，右边的人对应橙色小牛；角色跟随原图位置，不因性别、长相或肤色调换。两个人的身体、衣服、手和姿势完全来自原图，脖子以下不能出现动物身体、四肢、尾巴或新衣服。

黄色大牛头圆鼓黄、浅奶油白大鼻吻、灰犄角、窄长方块眼和细黑眉；橙色小牛头脸明显更小，橙棕色、白鼻吻和小犄角。两张脸必须明显不同，不能只换颜色；“更小”只描述头脸设计，不缩小原图人物身体。角色像低分辨率旧动画截帧：粗贴图、少色块、明暗直切、边缘略不稳、清晰度低于真人照片。保留合照中的不对称、近距离、有人走神或视线不一致，不要把废片式关系整理成双人写真。不要像素画、游戏 UI、故障艺术、精致 3D、毛毡、陶土、写实毛发或高级潮玩。

照片去饱和、低反差、青灰偏冷，下方三分之一适度压暗放字；只调照片色调，不能新增或替换背景。片名固定为“牛来”，朱砂红粗毛笔大字，旁边一枚朱红印章；下方只放 `NIU LAI` 和一两行简短中文信息。不要金色桂冠、真实影展奖项、四栏演职员表、长篇英文、商业大片字体或水墨画。中文一律简体。
