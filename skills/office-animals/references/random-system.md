# 随机系统与匹配原则

随机系统只补齐用户没有提供的部分。脚本 `scripts/draw_brief.py` 是当前运行数据源；本文解释选择逻辑，方便后续扩充。

## 动物家族

| 家族 | 当前动物池 | 更适合的动作 |
| --- | --- | --- |
| 灵巧前爪 | 猫、浣熊、水豚、兔子、松鼠、熊猫、熊 | 守电脑、按按钮、翻文件、碰咖啡杯 |
| 攀握型 | 猴子、猩猩、树懒 | 键盘、打印机、汇报、电话 |
| 大型四足 | 牛、马、驴、羊驼、山羊、鹿 | 闸机、走廊、会议桌边、述职现场 |
| 鸟类 | 鹅、鸭、鸡、鸽子、猫头鹰、鹈鹕 | 咖啡机、打印区、前台、夜班工位 |
| 多触手 | 章鱼 | 多屏工位、打印机、同时处理多项任务 |

用户指定池外动物时保留原物种。场景从会议、述职、夜班、走廊等对精细抓握要求较低的方向里选择，再由语言模型按照真实身体结构调整动作。

## 场景家族

| 场景 | 画面动作 | 默认版式 |
| --- | --- | --- |
| 表格工位 | 守着密集表格，盯住爆红单元格 | `headline-photo` |
| 周会现场 | 占据会议桌显眼位置，认真听但明显没跟上 | `full-bleed-editorial` |
| 咖啡续命 | 守着咖啡机或杯子，等待恢复工作能力 | `headline-photo` |
| 打印机卡纸 | 与吐出半截纸的打印机僵持 | `headline-photo` |
| 门禁冲刺 | 赶向闸机或打卡机，动作带明确方向 | `cutout-motion` |
| 绩效述职 | 面对表格、投影或资料册接受审视 | `full-bleed-editorial` |
| 深夜加班 | 独自守着发光屏幕，办公室已经空了 | `headline-photo` |
| KPI 汇报 | 在投影或白板旁展示无法解释的数据 | `full-bleed-editorial` |
| 前台接线 | 守在电话、访客本或接待台前 | `full-bleed-editorial` |
| 电梯偶遇 | 抱着文件或工牌等电梯，气氛安静尴尬 | `cutout-motion` |

## 匹配顺序

1. 先锁定用户明确给出的动物、场景、情绪和标题。
2. 缺动物时，从当前场景允许的家族里抽一只。
3. 缺场景时，从当前动物能自然完成的场景里抽一个。
4. 动物与场景都缺时，先抽场景，再抽兼容动物。
5. 版式跟随场景空间：静态近景用 `headline-photo`，多人尺度或宽空间用 `full-bleed-editorial`，移动动作与大留白用 `cutout-motion`。
6. 标题从当前场景的短标题池里选择；用户给出标题时原样保留。
7. 蓝色边注由场景与情绪生成五组核心标签，再从通用办公室状态词库和微型栏目词库补齐。`full-bleed-editorial` 目标约 15 组，`headline-photo` 约 13 组，`cutout-motion` 约 11 组；版式越能容纳边注，信息层越密。

## 动态文案层级

| 层级 | 来源 | 作用 |
| --- | --- | --- |
| 核心标签 | 当前情绪与场景专属短句 | 用中号字解释这次画面，固定 5 组 |
| 辅助短句 | 情绪匹配词与通用办公室状态词 | 用小号横排、竖排和信息框增加叙事密度 |
| 微型栏目 | 状态栏、备注栏、任务清单等中性栏目名 | 用极小字填充边角与窄栏，不编造公司和绩效数据 |

运行脚本输出 `blue_copy_tiers`，最终 Prompt 分层放置。用户自定义场景和池外动物同样走这套层级，只把核心标签换成当前情境，辅助与微型词库保持通用。

随机的目标是每次出现一个成立的小情境。荒诞感来自动物与工作制度的错位，动作本身仍然清楚、可读、符合身体能力。

## 多张随机

用户一次要求多张随机图时，先抽取候选，再选择动物、场景、标题互不重复的一组。数量允许时覆盖不同动物家族，并让 `headline-photo`、`full-bleed-editorial`、`cutout-motion` 三种版式都出现。情绪尽量不重复；需要消除重复时只重抽重复字段，保留已经随机得到的其他字段。
