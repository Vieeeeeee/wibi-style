# 牛马宇宙动态生图 Prompt v10

创作一张 3:4 竖版「Y2K 中文杂志广告式荒诞打工人海报」。

## 运行参考职责

每次携带  作为唯一风格与字体参考。它只提供红色中文大标题的手工拼字方式、蓝色边注的字号层级与自由排布、自然机顶直闪光感、红色剪贴描边、90年代胶片铜版纸质感和早期中文 DTP 气质。当前用户需求和动态设定独立决定动物、场景、动作、道具、构图落点与全部文字。参考图里的牛、绿色桌面、显示器、键鼠、Photoshop 画面、原标题、英文、红色旁注和具体构图都不进入新图。

## 本次内容

画面唯一主角是一只 {ANIMAL}，处于 {SCENE}。它正在 {ANIMAL_BEHAVIOR}，整体精神状态是 {MOOD}。呈现完整、可辨认的真实动物身体结构，让动作顺着这个物种真实拥有的嘴、爪、蹄、翅膀、触手、躯干与关节成立。办公道具的位置和尺度配合动物身体，荒诞感来自它认真上班的事实。

## 构图

采用 {LAYOUT}。让动物、办公环境、顶部标题和蓝色边注共同组成完整海报。主体位置清楚，办公室场景一眼可认，屏幕、桌面、打印机、咖啡机、会议桌、工牌、文件或门禁只保留与当前场景有关的少量物件。

## 摄影与印刷

画面呈现 1990s–2000s 经典自然直闪与复古杂志印刷质感：
1. **90年代自然机顶硬直闪**：机顶硬直闪从镜头正前方打出，近景桌面、会议资料与道具呈现清脆明亮的高光反差，光线由中心向四周自然柔和过渡。背景白墙通透干净，仅有非常轻微自然的光照衰减，绝不做大面积发黑发脏的假暗角或边缘黑晕。
2. **细腻胶片与光滑铜版纸质感**：全图覆有极细腻均匀的彩色胶片微粒（subtle film grain）与早期中文杂志光滑铜版纸的轻微套印质地，颗粒细腻自然地融入照片、红字与蓝字，整体保持暖灰纸白浅亮、画面干净通透，没有脏点或重度做旧灰雾。
3. **低清 DTP 印刷痕迹**：局部呈现轻微的早期数码压缩白边与手工剪贴排版轻微抖动。

## 海报系统

- 顶部放置超大简体中文标题：{HEADLINE}。逐字准确，只写这几个字，不追加句号、逗号、引号、书名号、感叹号或任何额外标点与符号。排成一行；一行放不下时按词义断成两行，不把一个完整词语拆到两行（例如「情绪」「设备」必须整词同行）。重点学习运行参考中的独立字形设计：像手工剪纸和早期 Photoshop 自制展示字，极粗笔画，横竖比例大胆拉伸，局部尖角、斜切口、外伸笔画和不对称负形；每个字的大小、宽窄、倾斜和基线略有差异，互相挤压、穿插、错位，同时保持清楚可读。颜色为朱红 `#C40D0A`。
- 动物外轮廓添加一圈不完全规整的朱红 `#C40D0A` 编辑剪贴描边，像早期 Photoshop 手工抠图标记，清楚且不发光。动物身体外缘保持干净，不沿动物毛皮身体轮廓排布蓝色文字。
- 四周蓝色文字统一属于中文宋体家族，使用深钴蓝 `#102C91`。学习运行参考中不同粗度宋体的自由混排：保留三角衬线、横细竖粗和印刷铅字结构，可以压窄、拉宽、竖排和改变字距，但保持清楚的印刷字形。配细线、箭头、复选框、资料栏、小印章和少量几何编号框。核心层和辅助层沿画面四周、桌面和场景留白分散落位，形成高密度但不平均铺满的中文杂志信息层；各组文字不统一装进相同矩形框。蓝色文字不使用手写体、楷体、行书、毛笔字、圆体或现代无衬线 UI 字体。
- 建立三层宋体边注：中号核心标签使用粗宋或特粗宋 {BLUE_COPY_CORE}；小号辅助短句使用中等字重宋体 {BLUE_COPY_AUXILIARY}；极小栏目标题使用细宋或报刊宋 {BLUE_COPY_MICRO}。核心层负责读懂这次场景，辅助层负责铺开打工状态，微型层负责贴器物。三层在字号、字重、方向和框线结构上明显区分。
- **微型与辅助字贴器物走线**：特小号边注与微型标签沿着画面中实际出现的办公器具轮廓边缘排布，顺着器具外轮廓折线、竖排或贴边延伸，并搭配极细引线和指示小箭头。这里说的器具（显示器、投影幕、白板、打印机、咖啡机、键盘、纸张、桌角、工牌等）只用来决定文字**放在哪里**，它们的名称本身绝对不写进画面。画面里不出现任何器具名称、方位描述或「边缘」「轮廓」「外沿」「侧面」「指示灯」「刻度」这类词，也不把器具名和栏目名拼成新标签。
- 画面中全部可读的蓝色中文，只能逐字来自本次给定的核心、辅助、微型三组变量，一个字都不额外发明。优先完整呈现全部核心标签，再尽量呈现辅助和微型文字。每一组文字在整张海报中只出现一次，不得把同一组文字放到两个位置来铺密度；也不要把核心标签额外排成一条横向流程条、目录行或页眉页脚重复一遍。空间还有富余时保留暖灰纸白留白，不新增任何文字；空间不足时从微型层末尾开始减少组数。不能用乱码、伪中文、随机数字、无意义英文、器具名称或重复词句填充密度。
- 屏幕、投影、白板、文件、工牌和办公设备只用不可读的浅灰线条、图表、色块或空白占位表达内容，不出现三层边注清单之外的可读文字。全部可读中文只存在于红色主标题和蓝色宋体边注中。
- 纸面和留白使用暖灰纸白 `#E3DEDA`。红色标题、蓝色边注、办公室照片形成清楚的三层视觉关系。
