# 影像蒸馏

## 先做影像蒸馏

### 1. 看完整照片

先理解人物正在做什么、身体和物件如何相互作用、哪些细节只属于这张照片。不要从“保留整张脸”开始。

### 2. 提出三种文字局部候选

内部至少比较三个不同尺度或不同部位的候选。候选名称必须具体，例如：

- “一只眼睛 + 蓝色发夹 + 发丝遮挡”；
- “嘴角 + 面条接触点 + 筷子尖”；
- “绿色指甲 + 筷子 + 碗沿”；
- “镜片中的眼睛 + 镜腿斜线”；
- “耳朵 + 耳钉 + 贴耳发丝”；
- “鞋面 + 脚踝纹身 + 裙摆”。

“脸部”“人物半身”“人物全身”不算完成候选命名。三个候选应尽量来自不同部位、尺度或观看关系，避免把同一个裁切换三种说法。

### 3. 选择最强候选

比较时依次看：

- 这块局部是否只属于当前照片；
- 是否存在清楚的接触、遮挡、穿插、重复或方向关系；
- 转成平面色块后轮廓是否依然漂亮；
- 缩成小框后能否一眼读懂；
- 是否有一到两个可以支撑整张配色的原片颜色；
- 是否比完整头像更有惊喜感。

把信息密度最高、图形关系最清楚的一项排为 A，并标注“推荐”；B、C 保留为真正成立的替代方向。面部只在眼睛、嘴、手、头发、镜片、道具或妆容共同形成事件时进入候选。

局部的“意外感”不能压过人物真正的辨识特征。遇到没有明显动作或道具的正面人像时，允许把“双眼 + 眉骨 + 发际线”作为完整观看关系；若双眼的神态明显强于单眼、耳朵或环境边界，优先保留双眼。不要为了制造陌生切片，把最有辨识度的眼神拆掉，再用砖缝、墙面等环境信息补足画面。

### 4. 用文字让用户选择

只描述将被放大的原片区域，不提前承诺框形、背景色或具体越框方式。使用以下简短格式：

```text
我从照片里找到了三个适合放大的局部：

A. <具体局部 + 关系>（推荐，<一句理由>）
B. <具体局部 + 关系>（<一句特点>）
C. <具体局部 + 关系>（<一句特点>）

回复 A、B 或 C；如果不想选，我会采用 A。
```

候选阶段只输出文字，不生成草图、不展示内部比较过程。用户选择只锁定放大区域；构图卡、出框方向、连接色和消失边线留到生成阶段独立判断。

### 5. 判断越框路径与连接色

收到用户选择或获准采用 A 后，再锁定局部，让生图模型根据原片自行比较一到三个越框可能：哪个真实元素具有最清楚的延伸方向，跨过哪一条框边最自然，露出多少仍能保持原片动作和结构。只要存在可信路径，默认选择其中一处执行，不需要用户提前指定。

越框选择服从局部事件本身。眼神最强时，可以让发丝、手指、镜腿或脸部轮廓承担越框；嘴与道具最强时，可以让吸管、筷子、面条、杯沿或手部承担越框；服饰和身体局部可以让袖口、裙摆、手臂、腿或鞋承担越框。保留最强观看重点，不为越框改选较弱的特写。

同时让模型从原片局部中寻找一处适合铺到框外的连接色，判断它能否在窗口边缘与框内真实色块直接接触。只要存在合理连接色，默认让框外底色采用同一准确色值，并删除同色接触处的那一小段框线。连接色与构图分别判断，不受构图卡占位色限制。
