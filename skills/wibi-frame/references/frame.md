# 参考图、裁切、框形、越框、画风与颜色

## 运行参考图

本 Skill 需要随包安装的 17 张风格参考位于 `assets/references/`。它们来自框景漫画特写项目的正式参考集；每张图的作用、适合的原片类型和 SHA-256 见 [SOURCES.md](SOURCES.md)。

处理用户照片时先完整阅读原片，再从这 17 张参考中选择最少且最匹配的一张主参考；只有当前局部同时需要另一种明确职责时才增加一张辅助参考。参考图只负责取景思路、框形、色彩组织和漫画质感，不提供人物身份、道具、固定文字或需要照搬的构图。将用户照片作为内容输入，将选中的本地参考图作为风格输入；不要要求用户再次上传这些参考图，也不要从网络补图。

调用图像生成工具时，明确说明每个附件的角色，不依赖附件顺序。若某张用户照片不需要参考图，仍可只使用用户照片和本 Skill 规则；不要为了凑数量无差别携带全部 17 张。

## 锁定真实裁切

在原片中确定一个真实存在的紧裁切区域，把它当作内容底稿。只保留完成局部事件所需的信息。

### 面部类

- 眼睛特写可以裁掉另一只眼、下巴或大部分额头；
- 嘴与道具特写可以只留下鼻尖以下、手指和接触点；
- 耳饰特写可以让耳朵、发丝和饰品占满框内；
- 完整头部只在手势、帽饰、烟雾或道具大面积遮挡并形成强图形时使用。

### 身体与服饰类

- 用胸口、项链、蝴蝶结和双手组成一个局部；
- 用交叉腿、鞋、脚踝和纹身组成一个局部；
- 用梳子、手与头发组成一个竖向动作；
- 用袖口、戒指、杯子或包带形成接触关系。

### 对应关系

漫画化只改变线条、平涂颜色、硬边阴影和少量印刷纹理。原图中的角度、接触点、遮挡顺序、手指方向、道具位置和饰品结构保持对应。无需补齐被裁掉的脸、身体或环境。

## 已蒸馏的截取逻辑

参考图用于判断局部密度、遮挡、框形与色彩组织；以下文字规则用于在不同原片之间保持共同风格：

- 眼睛、嘴与围脸手势：优先保留眼神、接触点和遮挡关系，让发丝、镜腿、手指或道具形成方向；
- 手与道具：突出抓、碰、夹、托、拨等具体动作，保留手指方向与物件受力关系；
- 腿鞋、领口、珠宝与服装：用轮廓、穿插和重复形状建立观看重点；
- 分段信息：仅在原片确实有两段对应关系时使用错位双框；
- 完整头部：只在发型、烟雾、帽饰或道具和越框共同成立时作为少数例外。

构图时先判断放大了什么、裁掉了什么、主体怎样压住框线，再决定具体颜色。不得模仿某一现成作品的人物、道具、文字或装饰。

## 选择规则框形

只使用四类清楚、稳定的几何窗口：

1. 长方形：眼嘴横向关系、脸与手、手与道具、服饰竖切；
2. 正方形：单眼、遮脸手势、妆容、紧凑身体局部；
3. 斜四边形：侧脸、斜向道具、倾斜视线；
4. 菱形：耳饰、中心手势、对称妆容与中心感强的局部。

框形跟随局部的方向和重心。框线可以被真实主体遮住，整体仍保持可识别的四边结构。

空白构图卡位于 `assets/layout-guides/`：

- 横向局部：`横向小框.png`、`横向小框_居中宽.png`、`横向小框_偏下.png`；
- 分段关系：`错位双横框.png`，只用于原片确实存在两段对应信息时；
- 紧凑局部：`正方形小框.png`、`正方形小框_偏上.png`、`正方形小框_偏右.png`；
- 斜向局部：`斜四边形小框.png`、`斜四边形小框_反向.png`；
- 中心式局部：`菱形小框.png`、`菱形小框_双层.png`；
- 头发、项链、竖向手部动作：`窄竖框.png`、`窄竖框_偏右.png`；
- 只需要纯色留白时：`纯色鼠尾草底.png`。

构图与颜色分别决定。先只根据局部事件的方向、重心、裁切范围和信息段数选择框形、尺寸与位置，不用模板颜色参与判断。构图卡中的现有颜色全部视为占位色，只读取几何关系。

构图确定后，再独立从原片辨识色和本 Skill 的复古色盘选择背景、框内主色与强调色。黑色、锈橙、酒红、芥末黄、靛蓝、钴蓝、灰蓝、鼠尾草绿与陶土色可以搭配任何合适的构图。不得因为选择某张构图卡就沿用它当前显示的颜色。

## 两步生成

### 第一步：只做好局部事件

使用真实裁切和已蒸馏的视觉规则生成平面漫画局部。让被选中的细节充满框内，保留原片接触与遮挡关系，同时保留选中越框元素的连续轮廓和延伸方向。此时重点看“特写是否成立”，暂时不追求整张画布的小框比例。

若第一步仍像完整头像、半身照或全身插画，立即判定失败，重新选择更紧的真实裁切。后续缩放无法补救取景错误。

### 第二步：缩小完整框景

把第一步已经成立的局部事件当作一个锁定的视觉单元，整体缩入构图卡。让选中的真实元素跨过最合适的一条框边，并让选中的连接色在另一处或相邻边界自然接入框外，再调整整组框景的大小、位置和外部底色。

缩小框景时保持框内放大倍率：眼睛、嘴、手、耳饰、腿鞋或服饰细节仍然贴近边缘并占满窗口。不能为了“放进小框”把被选局部重新缩成完整人物。

最终框景沿主要方向占画布约 30%–40%：横框看宽度，竖框看高度，正方框与菱形看宽度。允许因越框轮廓略微超出，但不能重新膨胀到画布一半以上，也不能小到丢失眼神、接触点或饰品结构。

第一步已经符合最终版式时可以直接结束。

## 越框与边界

默认优先实现一处主体越框。让生图模型根据原片的动作、轮廓、遮挡和构图重心，自行判断具体由什么元素越框、穿过哪条边、延伸多远。越框必须来自被选局部的真实方向：

- 面条、烟雾、帽带、发丝、衣摆等线性元素可以延伸出去；
- 手掌、手臂、膝腿、鞋等大形体只保留一处最清楚的越框；
- 细长工具只有到边证据时可以停在框线形成张力；
- 原片完全没有可连续延伸的主体、道具或负形时，才让主体完整留在框内，并优先尝试颜色融框。

越框轮廓必须从框内事件连续生长。外部底色紧贴真实轮廓，不留下抠图多边形、色块补丁或光晕。

主体穿过框线时，主体处于前景，交叉位置的框线必须被主体完整遮住。杯子、手臂、腿、烟雾或发丝的连续轮廓上不能横压一条框线；框线只在主体两侧重新出现，清楚表达“从框内穿到框外”的前后层级。

在主体越框之外，默认继续尝试“颜色融框”：当框内一个真实存在的大色块自然延伸到窗口边缘，并且外部底色采用完全相同的颜色时，删除两者交界处的对应框线，让框内色块无缝流进框外。其余边线、转角或主体轮廓继续提示原本的规则框形。只要原片中存在可用连接色和真实触边关系，就尽量同时实现主体越框与颜色融框。

颜色融框遵守三点：

- 共享色来自原片局部中的衣服、墙面、头发、道具或负形，不能为了拆框临时制造色块；
- 框内与框外使用同一个准确色值，不使用“接近的两个颜色”、渐变或光晕伪装连接；
- 只删除共享色真正接触边界的那一段框线，保留足够的直线与转角，让长方形、正方形、斜四边形或菱形仍然可读。

同一张图优先保留一处最清楚的主体越框和一处颜色融框。两者可以发生在不同边，也可以在同一方向协同；若边框被拆得无法辨认规则图形，恢复更多边线。

## 画风

采用复古美漫与旧印刷流行漫画的直接图形感：

- 外轮廓使用粗、稳、果断的黑色墨线，人物边缘、手指、眼睛、嘴唇和道具轮廓在缩略图里仍然清楚；
- 内部结构线明显少于外轮廓，只留下表情、关节、衣褶和接触关系真正需要的几笔；
- 用大片黑色阴影和明确负形组织体积，避免依赖密集细线塑造；
- 使用三至五种哑光平涂色，每个区域最多一层硬边阴影；
- 网点、排线和纸张颗粒只做旧印刷气味，不能覆盖皮肤、头发或衣服形成琐碎噪点；
- 人物辨识依靠粗轮廓、黑白块、配饰、动作与局部结构。

避免细线日漫式描摹、写实素描排线、逐根发丝、细密皱纹和大面积颗粒。皮肤、鼻梁、嘴唇、眼睛、玻璃和金属都先被概括为大色块，再用极少高光或黑块点明材质。

生成后缩小到手机缩略图检查：若首先看到一团细线和颗粒，或眼睛、手、杯子等核心轮廓被纹理吃掉，画风判定失败。应回到粗轮廓、大黑块和更少内部线重新生成。

## 颜色关系

完成构图选择后，再从被选局部中寻找一到两个原片辨识色，独立确定外部背景色、主体主色、深色和少量强调色。必须主动寻找一个既能留在框内、又适合铺满框外的“连接色”；只在确实没有合理候选时，才使用与框内完全分离的外部底色。

颜色联系优先依附局部事件：

- 把指甲、发夹、眼妆、帽子、鞋或道具的小面积颜色扩大为外部底色；
- 让越框主体把框内主色带到外部；
- 让外部底色沿真实负形进入框内；
- 让连接色在框内触边的位置取消边线，直接与框外同色区域合并；
- 原片颜色不足时，从本 Skill 的复古色盘中选择三至五种哑光平涂色，同时保持明暗层级对应原片。

外部背景保持单一平涂色。模型制造暗角时，只校正框外连通底色，完整保留框景和真实越框轮廓。收尾后检查四角、上下和左右留白，同时检查越框边缘是否干净。
