# Wibi Style · 暖纸蜡笔街拍

把一张真实人物照片重绘成象牙白纸面的粗蜡笔时尚编辑插画：笨拙的大色块形体、只剩三到五个图形的符号化小脸、一处电光蓝或柠檬黄跳色，以及三个粗钝手写的大写英文单词，像独立服装小刊里的随手街拍记录。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/warm-paper-crayon-street
```

安装器只下载这一款 Skill。装完不用做别的，第一次调用时它会自己打招呼并告诉你下一步。

上传一张人物照片就能用，头像、半身或全身都可以。照片决定人物、姿态和穿搭，内置参考只决定画风；半身照不会被补画腿脚。本款运行需要 1 张内置参考图，用户不需要再次上传。用户照片只用于当前任务，不进入安装包。
