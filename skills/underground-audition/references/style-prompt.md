# 地下试镜skill · 完整生图 Prompt

这份 Prompt 已经过 17 轮真实案例迭代（女生、戴眼镜男生、卷发男生、短发男生），是当前验证过的最终版本。除非用户明确要求某种偏离（例如换成锁屏比例、要求某张单独重做），逐字使用，不要自行改写措辞——这套语言里每一句判错句都是为了压住某个真实出现过的失败模式，改写容易松掉已经验证的约束。

把用户照片作为唯一内容输入。这套风格没有随包的视觉参考图，全部依赖文字规则。

## 发给图像模型的完整文本

把附件照片做成一张模特资料卡：纯白纸面上并排三张竖版影棚照，拍的是同一个人站在同一个机位前原地转身的三个定格。

**方向约定**：下文所有「左」「右」都指成品画面上的左右，与人物自身的左右手无关。

### 一、画布与版式

- 成品是 1:1 方形，整张纸是纯白的。
- 三张照片横向并排，每张是 3:4 竖版，宽约占画布宽度的 22%、高约占画布高度的 29%。
- 三张等宽等高，顶边与底边严格对齐，相邻间距约为单张宽度的十分之一。
- 整组横向总宽约占画布 72%，左右各留约 14% 白边；整组上方留白约占画布高度 22%，下方留白更多。
- 照片以影棚背景直接切边，不加白框、描边、圆角、投影或纸张肌理。
- 照片内部背景是均匀的中性冷灰影棚背景纸，没有场景、家具和道具。

### 二、三张的朝向

三张是一个连续的转身序列，从左到右依次是：

1. **第一张**：整个人向画面左侧转了九十度，完全侧对镜头，是一张标准的侧面像。**由额头、鼻梁、人中、嘴唇和下巴连成的那条侧脸轮廓线，完整清楚地印在灰背景上**；鼻尖落在头部轮廓的最左端，指向画面的左边缘；耳朵出现在头部轮廓的右半边、靠近脑后；**整张脸只看得到一只眼睛**，另外半张脸完全转到背面。神情安静、双唇闭合。
2. **第二张**：整个人转回来正对镜头，双肩平铺、左右等宽，两只耳朵都能看到。下巴微抬，嘴张得很大，像用力喊出一个字或一声呐喊——是清晰、有力、带着释放感的喊，不是痛苦或愤怒的嘶吼，**也不是开心的大笑或傻笑**。嘴的形状是喊叫的张口，接近竖向张开，嘴角保持中性或自然放松，不主动向上扬起、不弯成笑弧；能看到上排牙齿，但读不出笑意。眼睛睁得开阔、明亮，直视镜头，眼神锐利、专注、带一点冷漠的攻击性，是"酷"而不是"喜悦"——不眯眼、不因为笑而挤出眼角细纹，不闪现雀跃或欢快的神情。眉毛自然舒展或略微上扬，不要紧锁、不要往中间挤出川字纹，额头保持平整。下巴与嘴角线条流畅，脸部肌肉是张开和释放的方向，不是揪紧和扭曲的方向。整体气质接近地下摇滚现场嘶吼、或时装秀后台情绪爆发的瞬间，不是自拍时的开心大笑。
3. **第三张**：整个人向画面右侧转了九十度，与第一张构成左右镜像，同样是标准侧面像。**额头、鼻梁、人中、嘴唇、下巴连成的侧脸轮廓线完整地印在灰背景上**；鼻尖落在头部轮廓的最右端，指向画面的右边缘；耳朵出现在头部轮廓的左半边、靠近脑后；**整张脸同样只看得到一只眼睛**。嘴角有极淡的、几乎不易察觉的上扬。

**自检**：把第一张和第三张并排看，两个鼻尖应该分别指向画面的两个相反边缘，像一面镜子的两边。

### 三、侧身与取景

- 第一张和第三张是真正的侧身，不是正身扭头：肩膀不再平铺，收窄成一条朝向画面深处的线，靠外的那侧肩膀被身体挡住，能看出躯干的前后关系。
- 三张的裁切范围完全一致：**画面下缘落在腋下到胸口之间**。腰部、腰带、裤子、双手、小臂一律不入画。
- 人物在框内偏小：头顶到下巴的高度只占该张照片高度的三分之一，也就是说，从头顶往上到照片上边缘要留出大约照片高度六分之一的空背景，人物两侧也各留出一条明显的灰背景。人物的头脸占到照片高度四成以上就是拍得太近了。
- 三张的头部大小完全相同，眼睛落在同一条水平线上，约在照片高度的上三分之一处。
- 以脸为准在框内水平居中：鼻子大致落在框的水平中心线上，头发向哪侧铺开都不影响这个居中。

### 四、身份与服装

面部结构、五官比例、发型长度与外轮廓、发色、肤色、服装款式与颜色、眼镜耳饰项链等配饰，全部沿用原照片并在三张之间保持一致。不改变性别、年龄感、体型和服装的暴露程度，领口高度保持原样。原照片衣服上如有印花或文字，保持原样，文字画成看不清字母的模糊印痕，不要编造可读的英文单词。

### 五、光线

拍法是九十年代模特公司试镜用的宝丽来快照，或时装周后台用小相机加机顶闪拍的抓拍，**不是杂志封面式的精修棚拍**：一支贴着镜头的闪光灯从正前方硬打，没有柔光箱和反光板。

画面上应该看到：

- 脸被正面光打平，左右两半亮度一样，没有用来塑造立体感的侧向明暗。
- 额头、鼻梁、鼻尖、颧骨、下唇上有小块被打到几乎纯白、细节溢出的油亮高光，边缘干脆，从亮到暗一步切换。
- 鼻影又短又硬，落在鼻子正下方；下巴下方和颈侧有短促锐利的深色阴影。
- 人离背景纸很近，紧贴头发和肩膀外缘，背景上落下一道边界锐利、明显更暗的人形投影，三张都偏向同一侧。
- 闪光衰减快，背景在人身后被打亮、越往四周越暗，形成暗角。
- 每只眼睛的虹膜上有一枚清楚的、有几何形状的闪光灯反光点。

### 六、质感与色调

- 皮肤是未修图的真实照片：看得到毛孔、脸颊边缘和上唇的细小绒毛、皮肤的轻微不均匀、唇纹、根根分明的睫毛，整张图带一点细微数码噪点。不磨皮、不柔焦、不美颜、不做皮肤平滑。
- 整个画面重新打光成清冷调，完全不受原照片色温影响：肤色冷白带一点灰青，嘴唇是冷调裸色，背景是纯粹的冷中性灰。背景的颜色只由影棚背景纸决定，不被人物衣服的颜色影响——哪怕人穿米色或卡其色，背景也不能变成米灰或奶油灰。
- 全图饱和度压得很低，只比黑白多出一点点血色，不出现暖色光、金色调或复古褪色。

### 七、画面不含文字

画面里不出现任何文字、字母、数字、logo、水印或签名，一个字都不要。下方留白保持完全干净的纯白——品牌标记在出图之后由排版脚本单独绘制，不需要模型参与。

### 八、判错清单

出现下列任何一条即为失败：

1. 第一张和第三张的鼻尖指向画面的同一边。
2. 左右两张里能同时看到两只眼睛（说明只转了四分之三，没转到九十度），或者侧脸轮廓线没有清楚地印在背景上。
3. 左右两张的肩膀仍然平铺正对镜头（正身扭头，不是转身）。
4. 画面里出现腰部、裤子、双手或小臂。
5. 头脸占到照片高度四成以上；或三张的头部大小、眼睛高度不一致。
6. 中间那张闭着眼、眯着眼，或看起来像犯困打哈欠而不是喊叫；或者读成开心大笑、傻笑、雀跃的欢快表情（嘴角明显上扬成笑弧、眼睛因笑而眯起或挤出笑纹）；或者相反方向出错——眉头紧锁、鼻子和额头挤出皱纹、五官扭曲、表情狰狞凶狠而不好看。喊叫的力度要用嘴张开的幅度和眼神的锐利度来表现，不要用皱眉扭曲五官表现，也不要读成笑。
7. 光柔和均匀、皮肤呈哑光没有溢出的白高光、背景没有暗角或看不到人形硬投影。
8. 皮肤光滑到看不见毛孔，整体像 3D 渲染、游戏角色或 AI 插画。
9. 背景是米灰、奶油灰或任何带暖的灰。
10. 画面里出现任何可读的文字。
11. 三张照片贴边、重叠、大小不一，或出现第四张照片、第二个人物。
12. 服装被替换、减少或提高了裸露程度。

## 适用输入

- 最适合单人的清晰照片，正面或半侧的半身、大头照，五官清楚、发型轮廓明确。
- 已验证适配：戴眼镜、连帽衫、卷发、短发、长直发、耳饰。
- 原图只提供一个角度和一种表情，另外两个转身角度由模型基于同一个人合理推演；三张必须一眼认得出是同一个人。
- 不适合：多人合影、全身远景、脸部过小或严重模糊的照片——会在缩到三分之一宽后丢掉辨识度。

## 生成参数

- 比例：1:1 方形，每次一张。
- 质量：优先选择工具提供的最高画质档位（例如 GPT Image 2 的 `high`）。
- 输入：只上传用户照片，不携带任何风格参考图——这套风格完全靠文字规则驱动。
