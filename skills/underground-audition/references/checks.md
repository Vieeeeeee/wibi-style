# 生成后检查

## 生成后检查

**这一步是本 Skill 的核心机制，不是可选项。** 这套风格要求图像模型凭空推演出照片里原本不存在的两个转身角度——尤其是右侧那张完整侧脸，在真实测试里，模型有时会只转到四分之三、露出两只眼睛，而不是真正转满九十度；这不是偶发小概率，测试中出现的频率足以让每一张成品都需要过一遍检查，不能假设第一次就对。

拿到生成结果后，按顺序核对：

**核心项（任意一项不成立，判定这次生成没有达到风格要求）：**

1. 左侧那张是否转到完整九十度——只看得到一只眼睛，侧脸轮廓线（额头到下巴）清楚地印在背景上。
2. 右侧那张是否转到完整九十度、并且与左侧构成镜像——同样只看得到一只眼睛，露出的耳朵与左侧相反，鼻尖指向画面右边缘。**这是历史测试中最容易失败的一项，重点看。**
3. 中间那张是否眼睛睁着、直视镜头、真的在喊叫（张嘴、能看到上排牙齿）——不是闭眼、眯眼、像打哈欠；也不是眉头紧锁、五官扭曲的狰狞表情。喊叫的力度靠嘴张开的幅度和眼神亮度体现，不是靠皱眉和扭曲五官。
4. 左右两张是否真的整个身体在转——肩膀收窄成一条线，不是身体仍正对镜头、只有脖子扭动。
5. 取景下缘是否落在腋下到胸口之间——画面里不能出现腰部、裤子、手或小臂。

**质量项（明显不成立时一并指出，但不单独触发询问重出；跟核心项一起失败时按核心项处理）：**

6. 背景是不是冷灰色，没有被衣服颜色带暖；
7. 是否看得出机顶直闪的硬光——高光有没有溢出、阴影短不短硬不硬、背景有没有贴着人形的硬边投影；
8. 皮肤是否保留毛孔和真实质感，没有被磨成 3D 渲染或插画感；
9. 三张的身份、服装、配饰是否彼此一致、和原照片一致；
10. 画面里是否真的没有出现任何文字。

**核对结果的处理方式（不允许任何变通）：**

- **全部核心项成立**：直接进入「排版与交付」，不用额外征求同意。
- **任意一项核心项不成立**：
  1. 依然把生成结果展示给用户——这是已经花掉的一次生成，用户有权看到实际结果，不因为没通过检查就藏起来。
  2. 用一两句大白话说清楚具体是哪里不对，例如"右边这张只转了四分之三，还能看到两只眼睛，没到完整侧脸"或"中间这张像在打哈欠，不是在喊"。不要背整份判错清单。
  3. 问用户"要不要再出一张？"，然后**停下来等**。
  4. **绝不自己决定重出。** 哪怕看得出问题、哪怕很确定重出大概率会更好，也必须等用户明确说"再来一张""重出""redo"这类话才提交下一次生成。用户说"嗯""知道了""继续"这类话不构成授权，不能当成同意重出。
  5. 用户明确同意后，用同一张原照片提交**一次**新的生成，不要因为没把握就连续提交好几次；新一轮结果同样要走一遍这份检查。
  6. 用户不回应重出的问题、明确说不用、或者转向别的反馈，就停在当前结果，不再主动追问，也不要事后又补一次生成。

这条规则的原因很直接：每一次生成都会消耗用户自己的生成额度或费用，重出与否是用户的决定，不是 Skill 的自由裁量权。
