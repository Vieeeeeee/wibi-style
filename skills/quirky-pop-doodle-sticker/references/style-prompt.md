# 怪趣波普涂鸦贴纸 Prompt（线上版）

将用户上传的一张照片制作成一幅 1:1 的高完成度“怪趣波普涂鸦贴纸”混合媒介海报。先从原照片中完整保留真实人物、宠物、产品或物件主体，以及与主体直接相关的关键道具；清除无关环境，把主体放到一块干净、连续、均匀的单一纯色背景上。真实主体保持摄影质感，二维涂鸦只负责建立专属互动和视觉节奏。

先从照片提取三至五个必须保留的锚点：脸部与身体轮廓、动作或视线方向、双手与手持物、服装或材质特征、需要一起保留的前景物件。保持主体的身份、数量、姿态、动作逻辑、关键物件、原始裁切和可见范围，不凭空补出画面外的身体、物件或环境。

彻底移除窗户、墙面、地面、桌椅、建筑、招牌、店内陈设、背景人物、街景、反光和原照片的环境阴影。根据主体和照片情绪，从暖白、浅天蓝、薄荷绿或浅珊瑚中选择一种纯色背景；背景必须平整、无渐变、无纸纹、无摄影颗粒、无图案、无场景残影，至少占画面约一半。主体下方最多保留一小块同色系扁平接触阴影，不生成环境投影。

把主体放在画面中央或略偏一侧，为头部、手部、关键道具和两侧轮廓留出安全边距，形成两块以上连续安静的留白。保持主体约六至七成视觉权重，背景始终比涂鸦更安静。

从照片的动作、轮廓或关键物件设计一个大型原创怪趣卡通角色作为唯一主互动。角色必须跟随主体的动作方向，或直接握住、依靠、环抱、延伸自、回应一个真实道具；不能只是站在主体旁边。角色的形状由本次照片的主体轮廓、物件形状或动作线生成，不固定套用某一种角色。若主体有多个物件，只选择一个作为主要呼应，避免产生第二个抢主体的角色。

再加入一至三个中型连接图形，分别从服装纹样、关键道具轮廓、手部动作或照片中的局部颜色转译而来。连接图形可以贴着主体轮廓、从手持物延伸、被手部遮挡，或在纯色留白中与主角色形成清楚的视觉路径；不搭建四角边框。小型符号控制在三至六个，只组成一至两个疏朗节奏群，服务于主互动和主体轮廓，不平均散落全画。

所有涂鸦使用粗而有弹性的纯黑手绘轮廓，线宽随形体转折变化，允许轻微断线、越界、错位和手腕抖动。内部使用叶绿、柠檬黄、珊瑚红、钴蓝、糖果粉、暖白及从主体提取的一至两种呼应色，形成鲜亮但克制的平面色块。只在主角色和一两个连接图形内部加入稀疏半调网点或短线排纹，纯色背景保持完全干净。

最终成品应像一张留白充足的青年文化杂志海报：第一眼读到真实主体和纯色舞台，第二眼读到由主体动作或物件生成的卡通互动，第三眼才看到少量网点和符号。所有涂鸦都能追溯到主体本身，画面干净、鲜艳、有辨识度但不拥挤。

不要把真实主体整体画成卡通、矢量人物或 3D 玩具；不要改变脸部身份、肢体数量、动作逻辑、关键物件、原始裁切或手持关系。不要保留或重建任何原照片环境，不要生成窗户、房间、街景、招牌、背景人物、桌椅或复杂地面。不要让涂鸦铺满四边，不要添加第二个大型角色，不要用小圆点和细线填补留白。不要生成可读文字、姓名、品牌、标语、对话内容或社交平台标志。避免渐变背景、背景纹理、全局网点、白边贴纸包、规则 emoji 阵列、随机装饰、环境阴影和主体边缘被涂鸦遮断。
