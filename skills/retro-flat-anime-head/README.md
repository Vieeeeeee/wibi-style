# Wibi Style · 复古扁平动画头

把一张照片重画成 90 年代电视动画的一帧特写截图：平涂蜜桃橘皮肤、一刀切的硬边阴影、干净的黑豆瞳孔、锋利发梢，整颗头扔在一整块高饱和纯色上。

人还是你，气质换了一层——不太好接近，却很有故事感。

原片里的墨镜、帽子、耳机、耳饰、香烟、脸上的贴纸都会一起画进去，连帽子上的字都保留。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 适合什么照片

- 单人，正面或半侧脸，五官和发型轮廓看得清。手机原图就行。
- 戴眼镜、墨镜、帽子、耳机、耳饰都不用摘，是加分项。
- 不适合：侧脸过大、遮挡大半张脸、多人合影、严重模糊、只有背影。

## 使用

发一张照片，然后：

```text
使用 $retro-flat-anime-head 处理这张照片。
```

背景色不用自己选，它会挑一个跟你对比最强的（橙、钴蓝、热粉、正绿、纯黑），并告诉你选了哪个。想指定直接说「用热粉底」。

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/retro-flat-anime-head
```

安装器只下载这一款 Skill。装完不用做别的，第一次调用时它会自己打招呼并告诉你下一步。

本款无需内置参考图。使用时只上传一张自己的照片。
