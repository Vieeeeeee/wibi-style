# 背景选项

一次只选一种。第一次生成前先询问：

1. **A｜默认白色（推荐）**：最干净，最接近独立大头卡贴。
2. **B｜复古大波点**：更活泼、有波普感。
3. **C｜柔和双色渐变**：更柔和梦幻。
4. **D｜蜡笔手绘小星星**：干净留白、可爱轻松，像孩子手绘的贴纸。
5. **E｜柔粉纯色**：柔和、甜美，接近淡粉摄影棚背景。

用户明确选择时按其选择执行。用户说“默认”“都行”“你决定”，或只要求生成而没有提出彩色背景时，一律使用 A；不得根据人物颜色擅自选择 B、C、D 或 E。

## A｜默认白色

- 视觉上是干净、没有明显颜色倾向的白色背景；使用轻微暖调的摄影白，接近 #FAF8F3，避免冷蓝死白，也不呈现明显米黄或奶油色。
- 无渐变、纹理、阴影、光晕、地面和空间感。
- 这是未选择背景时的固定默认项。
- 默认不加白边。

## B｜复古大波点

- 使用大颗、等大、等距、边缘清楚的圆点。
- 候选配色：粉红底＋乳白点，蓝绿底＋浅黄点，象牙白底＋深色点。
- 当头发、帽子或发饰与某候选色接近时，改用另一组。
- 圆点只在背景，不进入人物头部。

## C｜柔和双色渐变

- 使用两种明亮、柔和、鲜活的颜色做平滑大面积渐变。
- 候选配色：粉红→杏黄，薄荷蓝→淡紫，珊瑚橙→桃粉。
- 无纹理、光晕、日落、风景或具体物件。
- 选择与头发、帽子和发饰对比最明显的配色。

## D｜蜡笔手绘小星星

- 保持干净的暖白背景底，接近 `#FAF8F3`；不做分区、渐变、纹理墙或复杂图案。
- 加入少量彩色蜡笔手绘小星星，颜色可用明黄、粉红、薄荷绿、天蓝、淡紫和橙黄；每颗星星有轻微不规则手绘轮廓、可见蜡笔涂抹纹理，但整体边缘仍清爽可爱。
- 星星以疏朗、大小有变化的方式分布在背景四周；允许少量星星跨到头发、耳朵或脸部外围，形成“画在照片表面”的轻微叠加感。
- 星星绝对不能遮挡或穿过眼睛、眉毛、鼻子、嘴巴、牙齿、耳饰和其他重要五官或身份特征；五官周围保留干净留白。
- 不加入文字、笑脸、涂鸦人物、太阳、云朵、彩带、贴纸边框、手、服装或其他装饰；不使用参考图中的人物、发型、眼镜、首饰、棒棒糖或妆容。

## E｜柔粉纯色

- 使用从用户参考图干净边缘区域提取的代表色 `#F3CCD1`（RGB 243, 204, 209）。
- 整片背景保持均匀纯色，视觉为明亮、温柔、略带灰度的樱花淡粉；不得漂成高饱和玫粉、紫粉、肉色或明显米色。
- 无渐变、纹理、阴影、光晕、地面和空间感。
- 参考图只定义这个背景色值；其中的人物、发型、犄角、首饰、妆容、棒棒糖、表情和光影全部忽略，不进入生成输入或成品。
- 默认不加白边；若浅色帽子或配饰与粉底实际混在一起，再按白边兜底规则建立下一版本。

## 白边兜底

1. 先选择与人物明度或色相差明显的背景。
2. 首次生成不加白边。
3. 只有结果中人物轮廓与背景混在一起时，才在下一 Prompt 版本添加均匀细白边，宽度为画布宽度的 0.8%–1.2%。
