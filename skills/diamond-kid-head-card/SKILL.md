# Wibi Style · 钻牙萌娃大头

将一张单人儿童老照片转换成写实大头卡贴。正式生成只上传内容老照片，不上传风格或背景参考图。

## 安装后作者卡与更新

每个新任务第一次使用时，先运行 `python3 {baseDir}/scripts/show_skill_info.py`。输出 `SHOW_SKILL_INFO` 时展示简短的作者卡，包含名称、版本、作者、同名平台、官方来源、交流学习群用途和“回复进群可获取当前二维码”；开场不直接展示二维码。输出 `AUTHOR_CARD_ALREADY_SHOWN` 时静默。署名不完整时建议从官方来源重新安装，不自动修复或覆盖文件。

随后运行 `python3 {baseDir}/scripts/check_update.py`。只有输出 `UPDATE_AVAILABLE` 时才用一句中文告知当前版、最新版和安装地址；`UP_TO_DATE` 与 `CHECK_UNAVAILABLE` 均静默，不阻断生图，不自动更新，也不上传用户照片或使用数据。

## 交流学习群

- 用户说“进群”、“群二维码”或等价表达时，运行 `python3 {baseDir}/scripts/community_info.py`。
- 输出中 `status` 为 `available` 时，简短说明群用途，展示入群链接，并用 Markdown 图片语法渲染 `qr_image_url`。
- `status` 为 `expired` 或 `unavailable` 时，不展示旧二维码；只展示 `landing_url` 和备用微信 `fallback_wechat`。
- 生图接口报错、空输出或超时时，先说明“这次没有成功生成，不会自动重新提交”，再按上述步骤展示一次当前群信息。同一对话只展示一次失败入群卡。
- 视觉验收不通过、用户取消、输入照片不适合或尚未选择背景，不触发失败入群卡。
- 展示二维码时附上提醒：群内交流请勿直接发送包含个人隐私的原图，可以先发错误提示或打码截图。

## 工作流程

1. 读取原片，识别人物身份、年龄感、脸型、五官、原始表情、肤色、头发、发辫、发揪、帽子、发饰和耳饰。
2. 第一次生成前读取 [background-options.md](references/background-options.md)，先询问用户想用哪种背景，并给出 5 个明确选项：A 默认白色、B 复古大波点、C 柔和双色渐变、D 蜡笔手绘小星星、E 柔粉纯色。A 标注为默认和推荐项。
3. 用户明确选择时按选择执行；用户说“默认”“都行”“你决定”，或没有提出彩色背景要求时，使用 A 默认白色。不得自行改选彩色背景。
4. 根据 [generation-rules.md](references/generation-rules.md) 组合生成指令。
5. 使用当前运行环境已经可用的图像生成工具或模型，每次生成 1 张 1:1 结果，优先使用无需用户额外配置的内置能力。某个工具不可用时继续寻找当前环境中的其他生图能力；确认没有任何生图能力后，请用户添加或启用可生图工具或模型。
6. 检查身份、头发完整度、构图、表情、钻牙条件、现代儿童摄影质感、背景和人物分离。未通过时报告具体问题，不自动重试。

## 固定结果

- 只有一颗完整人头、头发和头部配饰；没有脖子、肩膀、锁骨、衣服、手或身体。
- 原图画框内可见的头发、发辫、发揪与配饰完整进入成品；原图已出框的部分才允许裁切。
- 保持原片嘴部开合和表情。明显露齿时才在每颗可见牙面密铺多颗小钻；闭嘴或几乎不露齿时不加钻、不造齿。
- 老照片只提供人物身份和头部特征，不沿用原片的暗沉曝光、昏黄环境光、褪色、棕灰色调、旧闪光灯质感或年代感。
- 人物必须重建为明亮、光鲜、可爱的现代儿童棚拍：暖润健康肤色、清亮眼神光、自然红润面颊、干净深色头发、柔和高调布光、清透中间调、鲜活颜色和轻微现代摄影纹理；避免灰雾、暗沉、爆光和蜡像皮肤。
- 一次只使用一种背景方案，不生成四宫格、拼图或方案集。
- 背景只改变大头外部；不将参考中的假发、彩妆、饰品、棒棒糖、人物表情或其他物件带入人物。D 选项允许少量蜡笔星星绘制在头发或脸部外围，但眼睛、眉毛、鼻子、嘴巴、牙齿和其他重要五官区域必须完全无遮挡。

## 背景与白边判断

- A 默认白色是常规结果；B、C、D、E 只在用户明确选择后使用。
- 优先用色相或明度差把人物与背景分开。
- 首次生成默认不加贴纸白边。
- 只有实际结果显示头发、帽子、发辫或配饰与背景混在一起时，才建立新版本，添加画布宽度 0.8%–1.2% 的均匀细白边并等待下一次“测试”或“生成”。

## 验收

1. 原人物是否可辨认；头发、帽子与配饰是否完整。
2. 是否严格只有大头，下巴以下直接进入背景。
3. 原片露齿时是否是“每颗牙面密铺多颗小钻”，而非每齿一颗大钻、牙钉、牙套或牙箍；原片闭嘴时是否未造齿。
4. 人物是否色彩清透、曝光克制、具有真实摄影质感。
5. 背景是否只使用一种选项，并与人物轮廓清楚分离。
6. 是否无文字、水印、对比图、分屏和多余物件。
