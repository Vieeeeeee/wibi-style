# Wibi Style · 蜡笔极简扁平画

把一张真实照片重绘成纯白纸面、蜡笔颗粒、极简五官和高饱和扁平色块的手绘时装插画。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 使用

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/crayon-flat-naive
```

安装后直接上传一张照片，并说“用蜡笔极简扁平画处理”。头像或半身照会优先使用近景风格参考；全身、坐姿或动作幅度明显的照片会优先使用全身参考。用户照片决定人物和内容，内置参考只决定画风。
