# 读图与动态询问

先识别照片是人物、风景、建筑、室内空间、食物、宠物、物件或混合场景，然后提取：

- 必须保留的身份锚点；
- 能直接观察的时间、天气、活动、空间和关系；
- 画面无法确认、但可能改变票根含义的信息；
- 适合成为标题或票务隐喻的一个瞬间。

## 什么时候问

只问会实质改变作品的信息，每轮集中成一到三个问题。问题来自这张照片，不使用固定表单。

- 人物照可能需要关系、称呼或这一刻的含义。
- 旅行照可能需要城市、地点、日期或行程节点。
- 建筑照可能需要建筑名、地域或空间用途。
- 食物照可能需要菜名、店名或一起吃饭的人。
- 日常随拍可能什么都不需要问，可直接把可见内容组织成一张诗性票据。

用户说“你来填”、“自动”或“看图发挥”时，不再追问非必要事实。用观察性、诗性或票务隐喻填写空缺，例如把精确地名改成 `NORTH WINDOW / 北向窗边`，把不确定日期改成 `LATE SUMMER / 夏末`。

## 选择纪念信息模式

票根要记住照片背后的事，生成前根据已有信息选一种模式：

- `fact-archive` 事实档案：用户有日期、地点、人物、事件或行程信息时使用，只记录已确认事实。
- `scene-observation` 场景观察：用户只给照片或说“自动”时使用，记录画面可见的人、空间、光线、天气、动作、物件和对比关系。
- `personal-memory` 个人记忆：照片的情感或经历比地理信息更重要时使用，只询问“这是什么时刻”、“和谁/为什么拍”、“最想留住什么”中真正需要的一到三项。

有多种都适合时，向用户给出两到三个具体选项并推荐一个。用户要求直接生成时，按现有信息选择，不因缺少背景故事而虚构精确事实。

## 纪念文字层级

- 中文 Hero 是整张票最大、最先读到的文字，也是这张照片的记忆索引。它把可确认的画面事实压缩成一段仍在发生的记忆，优先组织城市与天气、动作或时间的关系，或人物、物件与光线、姿态、前后时刻的关系。
- Hero 使用二到八个汉字，保留一个具体锚点和一个有余味的关系。主体名称、活动名称和静态场景描述放入信息格；情绪判断与补充含义放入副标题、`WHY` 或 `KEEP`。
- Hero 读起来像一句被截短的叙事，优先保留动作发生前后、时间仍在延续或人与环境互相作用的感觉。事实短语继续转化到这层关系后再成为 Hero。
- 城市名在用户确认，或清晰地标、交通系统、可读文字、文件元数据与可靠来源形成高置信度证据时进入 Hero。证据不足的城市停留在候选判断，不写入票面事实。
- 自动填写时先拟出三个侧重点不同的 Hero，再选择最能让读者回到照片瞬间的一句。分类式命名、泛化抒情和地名堆叠在选择时淘汰。
- 英文标题作为辅助，字高约为中文 Hero 的 `25%–40%`，不与中文争夺焦点。
- 英文标题用自然英文重述同一个瞬间，可以调整语序与意象，事实范围与中文 Hero 保持一致。
- 信息区固定四个大格，每格只记录一个最有纪念价值的信息。优先从地点或地标、日期或场景、人物或事件、最想留住的事中选择；其中最多一格可以用从照片提取的图案、符号或印章替代文字。
- 排版导引图中的字体只表达字号、位置和阅读层级，不指定最终字体。图像模型根据所选风格参考设计 Hero 与功能字的字形关系，并让两者保持明显区别。
- 大小字必须形成明显的尺度跳跃，中间不堆积多层相似字号；其余背景信息由标题、短句和票号承载，不继续增加表格。

## 选图像方式

- 人物身份、建筑结构、食物细节或真实地点很重要时，推荐 `faithful-print`。
- 用户要求插画、漫画、手绘、梦境、象征或强烈改造时，推荐 `artistic-redraw`。
- 两者都成立时，用一句话说明取舍并让用户选一种。
- 用户说“你选”时，人物和纪实场景默认 `faithful-print`，其他题材按作品惊喜感选择。
