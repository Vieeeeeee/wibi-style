# 四套票根预设

四套预设共用 `2048×769` 横幅、左侧票面与右侧图窗结构。右侧图窗宽 `576px`，占整图 `28.125%`，图窗从 `x=1472` 开始。票面与照片依靠纸色和图版密度自然交界，不绘制贯穿全高的竖分割线。数值是可执行的起点，标题长度和主体裁切可在本预设内适配。

## orbit-orange

- 纸张 `#ECE9E3`，主墨 `#090909`，强调墨 `#E35F23`。
- 右侧照片是高反差黑色影印版，高光直接露纸，不在照片里使用橙色。
- 主标题使用超粗无衬线；副标题与表格线由橙色版承担；精确信息使用黑色。
- 文字路由：`kicker` 替换左侧竖排字，`serial` 使用照片前的竖排票号槽，中央依次容纳 `hero`、`title` 和 `subtitle`。
- 适合太空、旅行、建筑、城市、展览和重要纪念。

## blossom-red

- 纸张 `#EBC2DA`，单一朱红墨 `#DC2D1D`。
- 图像、文字和线框都来自同一块墨版，通过网点密度形成深浅，纸张是唯一的亮色。
- 主标题是宽幅几何无衬线，中间允许一枚花形冲孔记号；资料带保持红色细线。
- 文字路由：`kicker` 与 `title` 位于 `hero` 上方，`subtitle` 位于下方，`serial` 与照片相关图案共享第四格。
- 适合人物关系、约会、食物、花木、夏日、街头和轻松瞬间。

## sketch-black

- 纸张 `#EFEEEA`，单一近黑墨 `#2F2F2F`。
- 照片转成线稿、影印块面和粗颗粒混合的黑白图版；人脸和关键轮廓仍要可辨认。
- 主标题用不完全均匀的线框字，小字使用窄体无衬线，整体留白比其他三套更多。
- 文字路由：`kicker` 与 `title` 位于 `hero` 上方，`subtitle` 位于下方，`serial` 替换左侧竖排票号。
- 适合人物、动漫气质、阅读、安静室内、青春叙事和手作。

## signal-coral

- 纸张 `#E46169`，单一近黑墨 `#29191A`。
- 右侧图版使用高密度黑墨与粗网点，亮部透出珊瑚纸色；允许大面积深色但保留主体轮廓。
- 主标题用超宽无衬线，一行衬线引语成为第二焦点；精细表格与高密度图片形成张力。
- 文字路由：只显示 `hero`、`title` 和 `serial`；`title` 使用 Hero 下方唯一的辅助标题槽，不显示 `kicker` 或 `subtitle`。
- 适合夜景、戏剧性人物、乐队、活动、强烈建筑和高反差街头。

## 共同印刷机制

- 图片先決定墨版角色，再做网点、断墨和套印细节；不使用整图单色滤镜。
- 纸张显式参与画面，纸纹、纤维和墨量波动使用固定随机种子，相同输入可复现。
- 标题、图像和信息带只有一个主焦点；票号、栏目标签和装饰线保持从属。
- 粗网点不覆盖小字，小字和数字必须沿用排版导引图的清晰字形和层级。
