# 成品检查

- 成品是横向完整票根，右侧照片约占三成；照片与票面依靠纸色和图版密度自然交界，没有贯穿全高的竖分割线。
- 信息带是单排四格，只含三条内部竖线；前三格记录核心信息，第四格容纳照片相关图案与该预设允许的票号。
- 照片中的主体数量、人物身份、姿态、建筑轮廓、食物主体或场景方向仍然可辨认。
- 只出现当前预设字段路由与四格记录中的文字；原始参考票的片名、日期、影院、票价、入场字样和票号均未残留。
- 中文 Hero 是唯一文字焦点，英文 title 明显从属；两者准确可读，允许与当前印刷风格一致的窄压、缺墨、重印或边缘波动。
- Hero 用时间、动作、天气或关系把画面事实组织成一段未结束的记忆，读感超越压缩后的照片说明；城市名具有用户确认或高置信度证据。
- 信息格使用克制的功能字形，不复制 Hero 的造型，也没有缺字、截断、重叠或伪文字。
- 完成图只使用预设定义的纸色与一至两个墨版；颗粒、网点和深浅来自物理印刷逻辑。
- 自动填写的文案来自可观察内容或明确的诗性转译，没有把猜测的人名、精确地名或历史信息写成事实。
- 黑底裁切图保持完整票面可读，四角裁口、照片分界两端的撕票口、分界虚线和侧边打孔清楚；透明裁切图的对应区域具有真实透明通道。

任一身份、文字或构图核心项不通过时，保留本次图像并报告具体问题。本轮不修字、不脚本覆盖、不自动重试；用户明确要求再试时才调整一个核心变量开始新一轮。
