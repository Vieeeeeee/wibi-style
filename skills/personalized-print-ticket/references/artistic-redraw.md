# 艺术化重绘方式

艺术化重绘与排版、文字和纸墨质感在同一次完整生成中完成。它只改变右侧照片的再现方式，不改变票面构图和逐字文案。

## 共同 Prompt 骨架

1. 先写用户原照中必须保留的两到四个身份锚点、人物关系和场景结构。
2. 说明这是对用户照片的重绘，不增加新人、新建筑、新食物、新标志或想象背景。
3. 只改变右侧图窗内主体的线条、块面、明暗和网点组织，不增加插画背景、装饰物或新动作。
4. 右侧图窗仍严格跟随排版导引图的窄幅构图和 `crop_focus`，不让艺术化图像向左侧票面溢出。

## 按预设添加

- `orbit-orange`：木刻或摄影制版式高反差黑白重绘，大片深黑、断裂边缘、粗颗粒和露纸高光。
- `blossom-red`：单色孔版插画，简化成连续块面与柔软网点，保留人物姿态、地标或食物轮廓。
- `sketch-black`：独立漫画线稿与影印黑块，手绘线宽略有波动，人脸细节克制而可辨认。
- `signal-coral`：戏剧性影印剪影，块面更大、暗部更重，只用边缘高光和少量中间调保留身份。

生成后先比对原照的主体数量、身份锚点、姿态和场景方向。未通过时保留本次结果并报告，本轮不追加处理。
