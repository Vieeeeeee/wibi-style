# Sketch Black 完整生成 Prompt

Use case: precise-object-edit + text-localization + compositing
Asset type: flat scanned black-ink manga/editorial ticket, final bitmap artwork

## 三份输入的权限

原始票根是本次编辑底图，完整保留它的横向比例、手绘线框字、黑白漫画制版、影印颗粒、不稳定细线与留白；它的原片名、人物、图标、票号、日期和机构名全部替换，不残留。用户内容照片只替换原票根右侧图像，它是人物身份、主体数量、表情姿态、服装物件、建筑与场景方向的唯一权威。排版导引图只决定新文字与文字长度所需的少量适配。

## 画布与构图

信息带严格保持单排四格，只画三条内部竖线，不添加横向内分隔，也不继承参考票中的日期、座位、影院或入场信息。

生成一张横向窄幅、边到边填满画布的黑白文化票根，比例与排版导引图一致。左侧约 72% 是宽松的纸面、中央线框标题和底部四个大信息格；其中最多一格使用从照片提取的简洁图案，其余格各保留一项核心记录。右侧约 28% 是用户照片的黑白漫画/影印图版。线格使用很细的黑线，线宽在行进中不均匀，有轻微断点、颜色深浅和手工套准偏差。成品是平铺扫描件，没有桌面、阴影、相框、手或模型展示。

## 字体与文字

主标题必须像用黑色细笔临时描画的空心字：字母与汉字轮廓有轻微的宽度变化、不圆滑弧线、双线不完全平行、局部断线和少量重描；它是认真但不完美的人工字，不是干净电脑 outline font，也不是儿童涂鸦。信息格的英文标签使用窄体工业无衬线或 OCR 票号体；中文记录值使用小字号票据宋体/明朝体骨架，字面偏窄、横细竖略粗、端点清楚，只带轻微缺墨。信息格中文不能像缩小的主标题，不能使用空心字、超粗黑体或强烈残缺字形。所有文字按“逐字文案”严格呈现，不改字、不重组标题、不生成伪文字。

## 纸墨与右侧图像

使用接近 `#EFEEEA` 的暖白纸与接近 `#2F2F2F` 的单一黑墨。纸张有细小颗粒、扫描灰尘和轻微纤维，但不变成黄色旧报纸。右侧用户照片转成独立漫画线稿、复印黑块和粗网点的结合：关键轮廓是断续手绘线，头发、衣服、建筑阴影或物体暗面是颗粒黑块，皮肤、天空或亮面大量露纸。将真实照片转译为漫画制版，不将人物改成无关的动漫角色。

## 最终约束

完成图像一张真实扫描的少量印刷票据，字形、线格和照片具有同一种手工制版误差。不使用干净矢量轮廓、数字铅笔滤镜、彩色墨、渐变、贴纸、撕纸、复古报纸边框、logo、二维码、水印或额外文字。保留用户照片中的真实主体、数量、关系、姿态与场景结构。
