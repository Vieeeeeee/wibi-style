# Blossom Red 完整生成 Prompt

Use case: precise-object-edit + text-localization + compositing
Asset type: flat scanned one-ink cultural ticket, final bitmap artwork

## 三份输入的权限

原始票根是本次编辑底图，完整保留它的粉纸朱红单墨、字形宽度、标题节奏、印刷缺口、孔版网点、信息网格与扫描纸感；它的原片名、影片图像、票号、日期、地点和标识全部替换，不残留。用户内容照片只替换原票根右侧图像，它是新人物、场景、姿态、物件和空间关系的唯一权威。排版导引图只决定新文字内容和文字长度变化后的必要适配，其他构图以原始票根为准。

## 画布与构图

信息带严格只有四个主格，并且只保留一排；不画横向内部分隔，不把四格拆成日期、时间、票价、座位等八个小格。前三格分别承载逐字文案中的三项记录，第四格承载指定图案。原参考中的日期、时间、价格、座位、票号和入场文字都不继承。

生成一张边到边填满画布的横向窄幅票根，视觉比例和排版导引图一致。左侧约 72% 是大量粉纸留白、超大标题和底部红色信息带；右侧约 28% 是用户照片的朱红单色图版。照片边缘依靠网点密度和露纸形成自然图版边界，不画贯穿全高的竖向分隔线。底部细线固定成四个大格，其中一格使用花形或从照片提取的简洁图案，其余三格各保留一项核心记录；线格只围绕信息区，不延伸成照片边框。没有模型展示环境、投影、桌面或额外边框。

## 字体与文字

主标题应当有旧票券印字的性格，并保持中文准确可读。模型结合本预设和参考票根自行设计字形，可选择适度窄压、轻微缺墨、墨边积压、局部重印或不齐的基线，让错误印刷自然发生；不把这些效果机械地平均铺在每个字上。表格文字使用另一套克制、功能性的票务排字，与 Hero 拉开字重、比例和质感差异。排版导引图中的字体只是尺寸和位置占位，不作为最终字体样式。所有文字按逐字文案精确生成，不变更字符。

## 纸墨与右侧图像

底纸是 `#EBC2DA` 附近的淡粉未涂布纸，仅使用 `#DC2D1D` 附近的朱红墨；所有深浅都来自同一墨色的网点密度和不均匀着墨，不出现黑色、白色墨或第二个红色版。右侧照片转成一块极简单色照片制版：大块红墨、粗颗粒中间调、亮部露粉纸、局部圆形缺墨和轻微水平制版条纹。主体仍需在缩略图尺寸可辨认。

## 最终约束

整张票像一次性孔版或实验性文化票券的真实扫描件，纸纹、字体、图像和线框共享同一个物理印刷过程。保留用户照片中的人、物、动作和场景关系。没有干净矢量字，没有数码发光，没有渐变，没有现代 UI 卡片，没有可爱贴纸，没有 logo、二维码、网址、水印或额外文字。
