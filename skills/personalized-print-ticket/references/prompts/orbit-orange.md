# Orbit Orange 完整生成 Prompt

Use case: precise-object-edit + text-localization + compositing
Asset type: flat scanned cultural ticket, final bitmap artwork

## 三份输入的权限

- 原始票根是本次编辑底图，完整保留它的横向比例、左右分区、字形气质、油墨吃纸、线条波动、粗糙影印和扫描触感。它原有的片名、影片画面、引语、等级、票号、影院名和标识全部替换，不残留。
- 用户内容照片只负责替换原始票根右侧的影片画面，是新图像中人物身份、主体数量、姿态、物件、建筑、食物和场景关系的唯一权威。
- 排版导引图只负责新标题、新文字内容和文字长度变化后的必要区块适配；其他版式细节继续以原始票根为准。

## 画布与构图

生成一张完整的横向窄幅票根，视觉比例严格跟随排版导引图，成品边到边填满画布，没有桌面、背景、手、阴影、相框或模型展示。左侧约 72% 是排版票面，右侧约 28% 是窄幅照片图版，二者以纸色和图版密度自然交界，不画贯穿全高的竖向分隔线。底部由不均匀细橙线构成单排四个大格，其中最多一格使用从照片提取的简洁图案，其余格各保留一项核心记录；不添加横向内分隔。

## 字体与文字

主标题是强壮、略窄、深黑的文化活动无衬线字，轮廓并不完美：字面有少量断墨、纤维空洞、局部变薄和墨边渗出，但每个字仍然准确可读。副标题用高饱和橙色粗体，小字用机械排字感的窄体无衬线。票号是针式打印机的稀疏点阵字。所有文字按“逐字文案”原样呈现，不改字、不意译、不补字、不增加伪文字。

## 纸墨与右侧图像

纸张是接近 `#ECE9E3` 的暖白未涂布纸，不泛黄；纸纤维、微小压痕与扫描颗粒在空白区域也可见。只使用近黑 `#090909` 和橙色 `#E35F23` 两块墨版。右侧用户照片转成黑色高反差摄影制版，亮部直接露纸，暗部是黑墨堆积，中间调由粗网点、复印断裂和不均匀墨量构成。橙色不进入照片图版。

## 最终约束

画面必须像一张真实扫描的小批量活版/孔版票根，线条和字形具有同一类印刷偏差，不是在干净矢量排版上覆盖一层通用颗粒。保留用户照片的主体数量、身份锚点、姿态和场景方向。没有第三种墨色，没有渐变，没有数码光滑字，没有撕纸拼贴，没有品牌 logo、二维码、网址、水印或多余图标。
