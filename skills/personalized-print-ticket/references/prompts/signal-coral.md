# Signal Coral 完整生成 Prompt

Use case: precise-object-edit + text-localization + compositing
Asset type: flat scanned coral-paper protest/cinema ticket, final bitmap artwork

## 三份输入的权限

原始票根是本次编辑底图，完整保留它的珊瑚纸、黑墨密度、强势字形、衬线引语、线格笔触、高反差影印气质和窄幅构图；它的原片名、口号、影片画面、票号、等级、地点和标识全部替换，不残留。用户内容照片只替换原票根右侧图像，它是新人物、物件、建筑、食物、动作和空间的唯一权威。排版导引图只定义新文字和文字长度变化后的必要适配。

## 画布与构图

信息带严格保持单排四格，只画三条内部竖线，不添加横向内分隔，也不继承参考票中的日期、时间、价格、座位或入场信息。

生成一张边到边填满画布的横向窄票根，严格跟随排版导引图的比例。左侧约 72% 以一个宽大、不规则着墨的标题为主焦点，标题下方是一行明显较小的粗体衬线引语；底部由细黑线固定成四个大格，其中最多一格使用从照片提取的简洁图案，其余格各保留一项核心记录。右侧约 28% 是高密度照片制版。成品是平坦扫描件，没有桌面、外部背景、浮雕、投影、折叠或模型展示。

## 字体与文字

本预设只保留两级主文字：中文 Hero 是唯一大标题，英文 title 使用参考票根中原本的衬线短句位置，作为唯一辅助标题。数据中没有 kicker 或 subtitle 时保持留白，不补写任何制作说明或中文引语。

主标题是大号、宽幅、结构略显笨重的无衬线字，字母宽度、字距和基线有极轻微的人工偏差。黑色字面有不均匀吸墨、纸纤维空洞、局部边缘渗出和小面积残缺，但每个字准确可读。引语是粗壮、略有打字机感的衬线字，小字是窄体机械无衬线，票号是稀疏针式点阵。所有文字按“逐字文案”原样生成，不重写、不意译、不增加字符。

## 纸墨与右侧图像

纸张是接近 `#E46169` 的珊瑚红未涂布纸，只使用接近 `#29191A` 的暖近黑墨。所有粉色、暗红和近黑差异都是纸色透过不同墨量形成，不是多块色版。右侧照片转成戏剧性高密度影印图版：暗部连成大面积黑墨，亮部通过粗网点、干涩残缺和边缘高光透出珊瑚纸色；主体轮廓和关键身份仍然清楚。

## 最终约束

整张票必须像用粗糙纸和单色黑墨实际印刷、再扫描得到的戏剧性电影票：线框、字形、实底色块和照片共享同一种着墨波动。保留用户照片中所有主体的数量、身份、姿态和场景方向。没有干净数码排版，没有多色渐变，没有半透明发光，没有撕纸拼贴，没有 logo、二维码、网址、水印或额外文字。
