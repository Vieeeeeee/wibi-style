# Font assets

`assets/fonts/NotoSansSC-VF.ttf` is distributed under the SIL Open Font License 1.1 in `assets/fonts/OFL-Noto.txt`. It is used only to render neutral layout placeholders; the image model designs the final typography.

- Noto Sans SC source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The four project-owner-selected ticket images in `assets/references/` are bundled as runtime references for the four named presets. The project owner selected them for this public Skill release under the package license; their project paths, SHA-256 values, and runtime roles are recorded in `SOURCES.md`.
