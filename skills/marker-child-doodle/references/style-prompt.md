# 马克笔童画 Prompt

每次使用用户上传的真实照片直接生成，不先把照片处理成 Q 版，也不把生成图再次作为输入。附件中已经是马克笔涂鸦的那张只借用画法，照片决定画谁、画什么。

只画照片里的人或动物：人数、姿态、动作、头的朝向、发量轮廓、服装类型与主色，以及耳机、帽子、眼镜等配饰都跟随照片。参考图的人、球衣、号码、球、队徽和任何文字都不进入结果。

夸张 Q 版：头身比约 1:2，脖子几乎没有，肩很窄，手是没有关节的团块，手指最多三根短刺，鞋是大色块。脸只有四笔——两条粗斜眉、黑色方块眼、一撇鼻、一条嘴，保持倔强神情。头发是一整块几何形，边缘毛刺；白底里涂实心黑。配饰独立成块压在头发之上。

轮廓用石板灰蓝粗马克笔：线粗、钝、抖，粗细不匀，转角对不齐，线头出头，局部有积墨疙瘩；全图只有三四处真正的抬笔断口，整体保持连续，不画均匀虚线。

全图不超过四色：石板灰蓝的线、照片里本人的肤色、一个服装主色、黑。死平涂，无渐变、明暗、高光和投影。主要色块内部尽量填满，减少白点、白洞和白丝；白色主要来自色块之间以及画面周围的有意识留白。色块边缘保留手涂的不齐、抖动、轻微错位和少量溢出，内部保持安静完整。

每个物件用最少的笔画概括，不贴着真实轮廓描；超过三笔才画得出的细节不画，不画衣褶、鞋带、反光和食物颗粒。环境全部删掉，只留主体正在触碰或使用的一两件物件；坐姿保留一条桌沿或支撑面线，不画整件家具。原图拍到哪就画到哪，半身不补腿；宠物同框时人和动物都要画。

明亮照片用白纸留白，昏暗或夜景照片用整幅手涂黑底，主体推向一侧并保留呼吸空间。构图不要塞满画面，动作或视线朝向的一侧适当多留白。

右下角加入一笔或少数几笔连成的潦草英文签名“wibi”，字母挤压、省略、歪斜、带拖尾，只能看出大概，不要工整字体或清晰 Logo。整体像小孩速写本上撕下来的一页，有轻微纸纹和扫描噪点，不做成矢量、干净线稿、动漫、赛璐璐或贴纸。
