# 电蓝网点海报完整视觉规则

将用户上传的照片重绘为一张 1:1 的电光蓝粗网点半调大头招贴，气质接近 Y2K 独立乐队唱片封套和街头复印 zine。用户上传的照片是唯一内容输入，决定“印的是谁”。

保留原照片的身份信息：五官比例与间距、脸型、发型外轮廓与块面走向、发色明暗、头部角度与视线、表情（尤其眼睛开合与嘴形），以及墨镜、眼镜、帽子、耳饰等关键配件。不改变性别与年龄感，不美化、不瘦脸、不换脸。处理宠物时，将同样的忠实原则应用到物种、脸部花纹、耳形、口鼻比例、毛色明暗、表情和配饰。

构图只卡头部并放到最大：肩膀、衣领和衣服全部裁掉，头部撑满整个方形画面，头顶与两侧头发顶到或轻微切出画框；下颌线和下巴尖必须完整可见，绝不能被下边缘切断。脸宽约占画面宽度七成，发顶到下巴约占画面高度八成。原照片里的场景、环境、家具、天空一律去掉。

人物或宠物只有纯白与纯黑两级，中间调交给很粗的圆点网点，头部宽度上只有约 55 到 80 个点，粗到一眼能数清，点与点之间有明显空隙，暗部并点后成横向粗线条。脸上必须同时有三层，缺一层就不成立：额头、鼻梁、上眼睑、上唇、下巴尖爆成形状明确的纯白高光，约占脸部面积三到四成；脸颊、下颌面、鼻翼两侧、耳廓铺一片可数的粗网点，约占脸部面积三到四成，由它负责脸的体积；眼窝、鼻侧、颧骨下方、下颌下方、颈部投影压成边缘生硬的实心纯黑形状块。阴影必须落在脸上，不能只落在头发、毛发和眉毛上。三层之间靠硬边直接切换，只在交界处留一格粗网点过渡，皮肤或毛发不保留柔和渐变。

守住原照片的明暗关系：深色头发和毛发转成实心黑块；浅色、漂染、金色、白色头发或浅色毛发仍然是白色或稀疏网点的浅色块，不能被压成黑色。深色镜片、深色帽子和浓密黑发整体塌成实心黑色块面，只留两到四块硬边纯白高光，读起来像一个图形化的面具；实心黑面内部散布少量反向的纯白小点作为发丝或毛发高光，不要做成完全平的死黑。

主体层严格保持黑白，不染上任何蓝色或彩色。背景换成整块平涂的高饱和电光蓝（接近 `#1B1BEE` 的纯正宝蓝），均匀无渐变、无网点、无纹理、无暗角。头部轮廓与蓝底之间是干净的硬边直接相接，轮廓外侧不允许出现蓝色描边、蓝色网点、蓝色光晕或过渡边缘。

蓝色空处加入一层扁平矢量图形：六颗无描边的实心五角星，三颗红色（接近 `#E01C1C`）、三颗黄色（接近 `#F5D40A`），沿对角交替配色，分别落在四个角与左右两侧中部，边长约占画面宽度的 7% 到 10%，各带不同角度的旋转，可以被头发或毛发的黑色块面局部遮挡，但不能压到脸和墨镜；星星不带网点和阴影。画面右边缘靠中下的位置放一条白色竖向装饰条码，由粗细不等的白色竖条组成且无需可扫；条码内侧排一行竖向、字距很宽的极小白色英文大写字母，不超过十个字符，语义中性，不出现品牌名、人名、平台标识或可识别商标。除此之外画面没有其他文字。

视觉层级依次是：占满画面的黑白大头、剩余的蓝色缝隙、星星与条码。网点只作用在头部，绝不覆盖蓝底、星星和条码。

结果应保持粗粝直接的复印招贴感。避免细密精致的报纸网点、整张脸均匀中灰、只剩空白纯白与细轮廓线、柔和灰阶照片、颗粒噪点滤镜、像素马赛克和覆盖全图的半透明纹理。保持下巴完整、浅色头发或毛发的明暗、主体纯黑白、单一头部以及干净无边框的方形构图。
