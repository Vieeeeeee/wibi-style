# Wibi Style · 蓝纸漫画大字海报

适合动作和穿搭清楚的人物日常照片，绘成蓝纸漫画海报；按照片设计英文大字，让人物与文字形成遮挡或承托。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/blue-paper-manga-type
```

安装器只下载这一款 Skill。装完不用做别的，第一次调用时它会自己打招呼并告诉你下一步。

本款运行需要的参考图：`0` 张。需要时已放在 Skill 自己的 `assets/references/` 中，会随本款一起安装；用户无需再次上传。
