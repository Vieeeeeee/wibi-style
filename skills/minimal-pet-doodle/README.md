# Wibi Style · 宠物极简线条

把猫狗照片里最有记忆点的动作，画成大面积留白、少量笨拙黑线和一小块毛色彩铅组成的稚拙涂鸦。姿态、视线和身体曲线清楚的照片更稳定。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/minimal-pet-doodle
```

安装后上传一张猫狗照片，并说“用宠物极简线条处理”。本款没有内置运行参考图，用户照片只用于当前任务，不进入安装包。

更适合：单只猫狗、动作或表情清楚、身体轮廓可辨、背景不遮挡主体的照片。

输入内容混乱、宠物过小或严重遮挡时，动作与品种辨识度会降低。
