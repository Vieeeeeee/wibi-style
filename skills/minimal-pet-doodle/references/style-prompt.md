# 宠物极简线条 · 线上版 Prompt

将用户上传的真实宠物照片转换为 1:1 极简稚拙宠物涂鸦。用户照片是内容依据：保留宠物种类、数量、头部方向、视线、姿态、身体曲线、动作关系和最有辨识度的毛色区域。只画照片中真实可见的主体与动作，不补充画外身体、道具或环境。

画面像小朋友只看了一眼照片后，凭记忆画下宠物的动作残影。使用 awkward animal sketch、unfinished pencil doodle、bad cute drawing、almost empty paper 的气质。先抓住一个最有记忆点的动作，再用开放轮廓和不完整手势形概括身体；用 1–3 组笨拙黑线表现动作方向，用 1–3 个微小黑色记号概括眼睛、鼻子和嘴。耳朵、尾巴与四肢只保留识别动作所需的短线。

只使用一小块与原宠物毛色呼应的干性彩铅或蜡笔色斑。色斑可以越过轮廓、留有纸纹和未填满区域。背景使用纯白、奶油白或浅米色纸面，至少 85% 连续留白。线条保留断点、轻重变化、试探痕迹和自然笨拙感；整体保持 one gesture、few marks、one color smudge、unfinished drawing、raw and clumsy feeling。

最终画面只包含宠物涂鸦与纸面，不含文字、水印、边框、复杂背景、完整描边、完整上色或精致插画式细节。方形构图保持原照片动作方向和视觉重心，主体周围留出宽阔呼吸空间。
