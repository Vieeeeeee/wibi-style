# 原色硬光都市 Prompt v8

【任务】将真实照片重构成建筑尺度的原色硬光都市摄影。画面像用明亮天蓝、珊瑚红、黑与白直接搭出来，颜色本身是空间结构，不是局部滤镜。整体冷峻、巨物感、干脆、疏离、高反差、平面化，像一张直接冲击视线的城市波普摄影。

【输入职责】真实照片决定当前城市、人物、交通工具、建筑、道路、天空及其空间关系，只保留原片真实存在的元素。钴蓝建筑峡谷参考只负责极白受光面、深黑阴影和锐利切割；原色都市街景参考负责明亮天蓝、珊瑚红与黑白色块的大面积并置，并决定蓝色基准。两张风格图的楼宇、车辆、信号灯和城市地标都不进入本次画面。

【构图】1:1 方形。可以做图片剪裁，以获取最佳构图。从原片中提取最强的透视走向和两至三个大主体，组织成红色建筑面、天蓝空间面与黑白城市剪影的对抗。红蓝都要在缩略图中一眼读成完整大形。

【融边拼贴】先铺一张满版明亮天蓝底纸，再把红色、黑白的建筑、道路、人物和交通工具像摄影剪纸一样叠在上面。天空与底纸使用完全相同的天蓝，两者无缝连通。四周露出约 2%–5% 的不完全等宽蓝色边缘，这是底纸在剪贴层周围的自然露出，不是独立画框。允许 1–3 个轮廓清楚的前景主体局部压住或跨过蓝色边缘，其余剪贴边界保持干净锐利，形成前后层级。

【原色构图】全图严格只使用四个主色层。原色都市街景参考的明亮天蓝 `#42A4FD` 约占 35%–45%，作为底纸与天空的统一主色；天空是绝对平整的纯色面，不画云、雾、光斑、阴影、色差或渐变。珊瑚红 `#FA605A` 约占 15%–25%，覆盖一个完整的建筑立面或道路几何平面；蓝黑 `#070708` 约占 25%–35%，用于建筑、植被、道路和次要主体的大片暗部；纯白 `#FFFFFF` 与少量冷灰约占 15%–25%，用于受光建筑、路面标线和少数高光面。珊瑚红和天蓝可重新定义原片中性建筑、道路或交通工具的色彩，不受实物原色限制。

【复古拼贴强化】将画面明确拆成三层。底层是满版天蓝底纸与同色纯平天空。中层是 2–4 块独立的建筑、道路与树影摄影剪片，每块保留完整硬切轮廓，相邻剪片交叠 1%–3% 且不完全对齐，少数接缝露出纤细白色纸边。前层是 1–3 个人物或交通工具剪片，它们覆盖中层接缝，并至少有一个主体局部压住或跨过蓝色底纸边缘。蓝色露边被剪片局部遮断，不形成完整矩形画框。

剪片保留复古冲印与丝网印刷的物理差异：红色或黑白剪片只在少数边缘出现 1–3 像素感的微小套色偏移，深黑面带少量粗颗粒油墨感，白色面有轻微旧印刷纸感；底纸与天空保持干净纯平。不加撕纸、胶带、报纸字、邮票或棕黄做旧素材。

【影调与质感】使用强烈 posterized photography，所有植被、交通工具、玻璃反光和其他材质都归并进四色系统，删去大部分自然色与中间调。若原片存在轮廓完整、视觉权重高的车辆、自行车或摩托车，选择 1–3 个作为独立单色主体：每个主体的车身或车架只使用珊瑚红或明亮天蓝其中一种主色，车窗、轮胎和阴影压成蓝黑，受光边缘留纯白。较大的交通工具可用红色，较小的可用天蓝，颜色对撞发生在不同空间与不同主体之间。其他次要主体保持黑白冷灰。受光面平整近白，暗面直接落入蓝黑，颜色之间是锐利硬边。树冠、远处小主体和窗格合并为大形，细节服从色面。保留摄影透视与轻微早期数码颗粒。

【判错线】把完整城市照缩小后放在等宽蓝色画框里是错的；所有剪片边缘完全对齐、没有交叠或越界是错的；天空与蓝色底纸之间出现分界线，或天空出现云、雾、渐变与任何色差是错的；单个车辆内部同时出现大块红蓝拼色是错的；满画面撕纸、胶带、报纸字、邮票、复古贴纸或棕黄做旧是错的。

【输出】输出 1:1 方形成片，无新增城市、建筑、人物、车辆、文字、标题、边框、水印或 Logo；原图已有道路文字只作为图形节奏弱化保留。排除局部保色黑白照、HDR、自然全彩、渐变调色、柔光、3D 渲染和细腻插画。
