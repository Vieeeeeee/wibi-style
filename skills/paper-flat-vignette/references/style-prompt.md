# 留白平涂小景 Prompt 线上版

【任务】把用户上传的真实照片重构成一张 1:1「留白平涂小景」编辑插画。最终成品像印在暖白纸张中央的一幅安静小画：场景完整收拢、四周留白、空间压平、色块明快、边缘略有手工感。正式生成只使用真实照片，不需要风格参考图。

【风格身份】使用 `editorial spot illustration`、`mid-century modern flat illustration`、`cut-paper collage shapes`、`opaque gouache color blocking`、`matte screen-print finish` 这一组专业风格锚点。它们分别对应：纸面中央独立成景且由内容形成外缘；中世纪现代编辑插画的简洁几何与有限配色；完整色纸剪形般的大轮廓；不透明、无水彩渗化的哑光平涂；低光泽、低噪点、干净克制的纸上印刷表面。画面始终保持平面、清爽、作者性手工边缘，不转成水彩画、动漫、赛璐璐、矢量图标或贴纸。

【内容依据】真实照片是唯一内容来源。先识别让画面成立的 2–5 个锚点：主要人物或对象的数量与轮廓、姿态和朝向、视线或动作、手与物件的接触关系、最重要的环境结构与位置关系。保留这些锚点及原图的左右次序、遮挡关系和颜色归属；只合并反光、纹样、品牌、远处杂物和不影响识别的细节。不增加照片中不存在的新人物、新物件或新故事。原片边缘已经出现、但被摄影裁切截断的棚顶、屋檐、树冠、墙体、台面、地面、家具或主体轮廓，可以沿其可见结构和方向适度延续，让这个已有对象在插画中获得完整、自然的收口；只补完整可判断的形态，不补造无法从原片确认的细节。

【居中构图】使用 1:1 暖白纸张画布。把原片重新组织为画布中央一个完整、紧凑的场景单元，整体约占画布宽度和高度的 72%–78%，上、下、左、右都保留连续、清楚、宽度接近的空白纸边。

中央场景的外边缘必须由画面内容自身形成：从原片现有结构中选择少量最能包住场景的边缘锚点，让横向棚顶、屋檐、树冠或横梁收住上缘，让柜台、桌面、地面、台阶或家具底座收住下缘，让建筑竖面、植物、家具或主体轮廓自然结束左右两侧。边缘锚点随当前照片选择，原片没有的类型不新增。允许把原片已经露出的截断结构补到自然终点，也允许删掉不重要的半截边角物；主体动作和关键接触对象保持完整。

不要把原照片等比缩小后塞进一个规则矩形，也不要在内容后面铺一块矩形、圆角矩形或无依据的波浪色底充当画面边界。中央小画可以有局部高低、穿插和轻微不齐，但整体重心稳定、轮廓有收束；所有内容不触碰画布边缘，不出血，不加外框线。四周暖白空白直接贴着场景自身轮廓出现。

【空间】采用正面、平视、近似正交投影的二维构图。把原片的前后空间压成少量相邻或遮挡的平面层，物件以轮廓、位置和明度区分，不用远近缩放和汇聚透视制造纵深。前后对象同等清晰；不出现摄影景深、镜头虚化、前景虚焦、空气透视、散景或伸入画布边角的模糊前景。

【形体】用概括的几何剪影和大块连续色面重画主体。人物保留可辨认的外轮廓、发型、服装大形、姿态、表情方向和手部接触点，五官与衣褶只用少量短促深色笔触；空间、家具、植物与物件先保留结构和数量，再压缩成简洁形状。细节服从识别与动作，不做写实描摹。

【色彩】以纸底 `#F1F1F1` 为最大面积，暖米灰 `#DBD1C5` 承担浅色大面，钴蓝 `#2855BC` 为主要强调色，深蓝 `#1D439B` 只作同色暗层，炭黑 `#0E1002` 承担最深结构，朱橙 `#EA602A` 只作小面积焦点；原片确有植物或自然对象时可用深叶绿 `#2F4B25`。肤色、发色与身份相关颜色沿用真实照片。全图控制在约 7–9 色，同一对象的颜色归属保持稳定，大面积平涂，基本无渐变。

【材质与边缘】色块内部连续、安静、完整填满，保持清爽的哑光平涂；内部不出现水彩刷痕、明暗碎片、白点、白丝或破碎孔洞。轻微手工感只出现在外轮廓的小幅不齐和少量笔触停顿。暖白纸底保持明亮干净，纸纹压到只有放大观看空白区时才略微可见；扫描噪点只是一层接近不可见的均匀细灰，不进入主体色块，不形成暗角、灰雾、污渍、斑点、擦痕或满画面的颗粒。

【光影】只用 1–3 组边界清楚的浅米灰或深色色块说明光照与承重关系。保持扁平、同等清晰的二维效果，不用柔光渐变、写实投影、反射或立体塑形。

【文字】原片中的菜单、品牌、Logo 和招牌统一简化成不可读的抽象色块。除文末指定的右下角 `wibi` 手写签名外，不新增其他文字、符号、边框或水印；签名只出现一次，不能替代主体或进入中央视觉层级。

【限制】保持真实照片中的主体数量、身份、动作、方向和关键接触关系。避免照片滤镜感、写实皮肤与材质、3D、矢量般完美边缘、精细线稿、复杂排线、水彩刷痕、厚涂、碎色、灰雾、脏纸、柔和渐变、景深、虚化、透视纵深、满版、铺满画布、贴边和主体裁切。

右下角加入一笔或少数几笔连成的潦草英文签名“wibi”，字母挤压、省略、歪斜、带拖尾，只能看出大概，不要工整字体或清晰 Logo。整体像从小孩速写本上撕下来的一页，但主体仍由清爽、完整的平涂色面组成；纸纹极轻，扫描噪点接近不可见，暖白底色明亮干净，不出现灰雾、污渍、斑驳或水彩刷痕。不做成矢量、干净线稿、动漫、赛璐璐或贴纸。
