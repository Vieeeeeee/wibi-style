# Wibi Style · 纸上人物志·CD版

适合人物日常照片：把动作与穿搭画成橙底日文扁平插画封面，装入透明 CD 盒，生成方形静态产品展示图。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/paper-portrait-cd
```

安装器只下载这一款 Skill。装完不用做别的，第一次调用时它会自己打招呼并告诉你下一步。

本款运行需要的参考图：`0` 张。需要时已放在 Skill 自己的 `assets/references/` 中，会随本款一起安装；用户无需再次上传。

## 两步复现

默认一次生成 CD 成品。需要分别保留平面封面与包装展示时，可按 [原两步提示词](references/two-step-prompt.md) 先生成封面，再将封面装入 CD 盒；执行前确认两次生图。
