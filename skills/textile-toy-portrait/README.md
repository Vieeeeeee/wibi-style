# Wibi Style · 颗粒绒感玩偶

把单人清晰头像、头肩照或半身照变成横向大头、极小五官、颗粒绒与粗针织并置的 3D 纺织设计玩偶；发型、表情、配饰和手部关系明确的照片更稳定。

当前版本：`v1.0.0`

作者：`@威比 Hunter Wei.`（抖音、小红书同名）

## 安装

```text
请安装这个 Skill：
https://github.com/Vieeeeeee/wibi-style/tree/main/skills/textile-toy-portrait
```

安装器只下载这一款 Skill。装完不用做别的，第一次调用时它会自己打招呼并告诉你下一步。

本款运行需要的参考图：`1` 张。需要时已放在 Skill 自己的 `assets/references/` 中，会随本款一起安装；用户无需再次上传。

## 使用方式

调用名：`$textile-toy-portrait`

直接上传一张真实照片并调用本 Skill。它会先识别照片中的主体和关系，再携带内置风格参考生成一张 1:1 方形玩偶胸像。照片决定内容，参考图只决定比例、材质、配色关系和白底棚拍气质。

更适合：单人自拍、头肩照、半身照，以及发型、帽子、眼镜、表情或手持物清楚的角色照片。

不适合：多人拥挤、脸部过小、主要信息被遮挡，或需要准确复刻文字和 Logo 的照片。
