# 线上版 Prompt

【任务】用用户上传的真实照片生成 1:1 方形 3D 纺织艺术玩偶胸像。真实照片是内容输入；内置白底颗粒绒玩偶图只作为视觉风格参考。保留照片里真实存在的身份、表情、姿态、物件关系，重构成夸张幽默的 designer toy，不做绒面滤镜。
【参考】内置风格参考只学习横向圆角巨头、极小集中五官和脸部留白、针织软雕塑/团簇、轻微不对称、细颗粒绒与粗针织反差、主次配色、白底棚拍；不继承参考角色的身体、动作、发型、帽子、眼镜、服装、道具或颜色。
【主体】真实照片是内容白名单：仅画照片中实际可见的人体部位、发型、服装、配饰、物件、姿势及接触关系，不补画画外内容。提取 2–5 个身份锚点，夸张 1–2 个，其余简化。脸为宽厚圆角方块/短圆柱；眼为极小黑珠/胶囊，鼻为小圆角积木，嘴按原表情变成短线/小开口；头发为大型毛线环/团簇。手数严格一致：无手不画，一只只画一只，保持方向、袖口和接触对象。文字/Logo 变成不可读织纹。
【构图】紧凑头肩近景，头占宽 75%–90%，身体压缩，只留必要动作/物件；可裁边，不新增画外身体。
【风格】stylized 3D textile art toy，oversized head and tiny features，sculptural knit forms，micro-flocked surface；抽象夸张高于写实，仍能由轮廓、姿态、物件辨认。
【色彩】自动组织 3–5 色：主色、明显冷暖/明度对比的强调色、辅助色、中性色；非身份区可改色，避免近单色、全中性、平均彩虹、机械条纹。
【材质光影】脸、手、零件用短密颗粒绒/fine felt；头发、帽子、服装用粗针织/crochet、毛线环/团簇。微暖白无缝背景，柔和高亮棚拍光，短轻阴影。
【限制】不保留写实眼球、鼻翼、嘴唇、皮肤、发丝；不复制风格角色，不新增照片没有的身体、手势、配饰、道具；不要普通 3D 卡通、塑料、软陶、蜡像、长毛绒、可读文字/Logo、房间或复杂背景。照片决定画什么，风格参考只决定怎么画。
